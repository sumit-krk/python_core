# Python Type Casting (Type Conversion)

**Important note:** Python does not automatically convert every type. For example, adding a number and a string causes an error:

```python
# print(5 + "2")  # TypeError
```

## 1. Implicit Type Conversion (Automatic)

Python automatically converts values only when it is safe and sensible—most commonly between numeric types.

### Numeric type order

When different numeric types are used together, Python generally promotes the lower type to the higher type:

```text
bool → int → float → complex
```

| Expression | Conversion | Result |
|---|---|---|
| `True + 5` | `True` becomes `1` | `6` (`int`) |
| `5 + 2.0` | `5` becomes `5.0` | `7.0` (`float`) |
| `2.5 + 3j` | `2.5` becomes `2.5 + 0j` | `(2.5+3j)` (`complex`) |

```python
result = 10 + 2.5
print(result)        # 12.5
print(type(result))  # <class 'float'>
```

### Boolean in mathematics

In Python, `bool` is a subclass of `int`:

```python
print(True + 5)   # 6  (True acts like 1)
print(False + 5)  # 5  (False acts like 0)
```

> Python uses capital letters: `True` and `False`, not `true` or `false`.

## 2. Explicit Type Conversion (Manual)

Explicit type conversion means **you** change a value’s type using built-in functions.

| Function | Converts to | Example |
|---|---|---|
| `int()` | integer | `int(3.14)` → `3` |
| `float()` | decimal number | `float("19.99")` → `19.99` |
| `str()` | string | `str(25)` → `"25"` |
| `bool()` | `True` or `False` | `bool(0)` → `False` |

### `int()` — float to integer

`int()` removes the decimal part. It truncates **towards zero**.

```python
print(int(3.14))   # 3
print(int(-3.14))  # -3
```

### `float()` — string to float

The string must contain a valid number.

```python
price_str = "19.99"
print(float(price_str))  # 19.99
```

### `str()` — value to string

Useful when combining numbers with text.

```python
age = 25
print("My age is " + str(age))  # My age is 25
```

### `bool()` — value to boolean

`False` values include `0`, `0.0`, `""` (empty string), and empty collections. Most other values are `True`.

```python
print(bool(0))       # False
print(bool(""))      # False
print(bool("Hello")) # True
print(bool(-4))       # True
```

> Even `bool("False")` is `True` because the string is not empty.

## Multiple conversions

Conversions can be combined from inside to outside:

```python
print(int(float("19.30")))  # 19
```

Steps: `"19.30"` → `19.3` using `float()` → `19` using `int()`.

## Practice exercises

1. Predict the value and type of `7 + 2.0`.
2. What will `False + 10` print?
3. Convert the string `"42"` into an integer and add `8`.
4. Predict the output of `int(-8.9)`.
5. What do `bool("")` and `bool("0")` return?
6. Convert `"15.75"` to a float, then to an integer.

### Answers

1. `9.0`, type `float`
2. `10`
3. `int("42") + 8` gives `50`
4. `-8`
5. `False` and `True`
6. `int(float("15.75"))` gives `15`
