# Python Programming - Semester 1

Welcome to the Python Programming course for Semester 1. This folder contains comprehensive learning materials covering fundamental concepts of Python programming.

## Course Structure

- **01. Intro to Python Programming** - History, basics, and execution
- **02. Data Types** - Primitive and complex data types in Python
- **04. Control Flow** - Conditional statements and loops
- **05. Lists, Tuples & Strings** - Data structures and string manipulation
- **06. Functions & Debugging** - Function definition, return types, and debugging
- **07. Modules & Packages** - Code organization and imports
- **08. Object-Oriented Programming** - Classes, objects, inheritance
- **09. File Handling & Standard Libraries** - File I/O and built-in modules
- **10. Advanced Python Concepts** - Decorators, generators, and more
