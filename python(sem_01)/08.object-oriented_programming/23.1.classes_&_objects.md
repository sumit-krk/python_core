# Classes and Objects

## Class Definition
```python
class Person:
    """A person class"""
    
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def greet(self):
        return f"Hello, I'm {self.name}"
```

## Creating Objects
```python
person1 = Person("Alice", 30)
person2 = Person("Bob", 25)

print(person1.greet())   # Hello, I'm Alice
print(person2.name)      # Bob
```

## Attributes and Methods
- **Attributes:** Data (variables)
- **Methods:** Functions within class

## Special Methods
```python
class Car:
    def __init__(self, model):      # Constructor
        self.model = model
    
    def __str__(self):              # String representation
        return f"Car: {self.model}"
    
    def __repr__(self):             # Official representation
        return f"Car('{self.model}')"
```

## Inheritance
```python
class Animal:
    def speak(self):
        print("Sound")

class Dog(Animal):
    def speak(self):
        print("Bark")

dog = Dog()
dog.speak()             # Bark
```
