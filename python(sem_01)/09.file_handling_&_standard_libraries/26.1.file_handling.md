# File Handling in Python

## Opening Files
```python
# Text mode
f = open("file.txt", "r")  # Read
f = open("file.txt", "w")  # Write
f = open("file.txt", "a")  # Append
f.close()

# Binary mode
f = open("file.txt", "rb") # Read binary
f = open("file.txt", "wb") # Write binary
```

## Reading Files
```python
# Read entire file
content = f.read()

# Read line by line
line = f.readline()

# Read all lines
lines = f.readlines()
```

## Writing Files
```python
# Write single string
f.write("Hello World")

# Write multiple lines
f.writelines(["Line 1\n", "Line 2\n"])
```

## Context Manager (Recommended)
```python
# Automatically closes file
with open("file.txt", "r") as f:
    content = f.read()
    print(content)
```

## File Operations
```python
import os

os.remove("file.txt")           # Delete file
os.rename("old.txt", "new.txt") # Rename
os.path.exists("file.txt")      # Check existence
```
