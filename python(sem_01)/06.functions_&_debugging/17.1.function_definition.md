# Functions in Python

## Function Definition

### Basic Syntax
```python
def function_name(parameters):
    """Docstring"""
    # Function body
    statements
    return value
```

### Simple Example
```python
def greet(name):
    """Greet someone"""
    return f"Hello, {name}!"

result = greet("Alice")
print(result)
```

## Function Components
- **Name:** Identifier for function
- **Parameters:** Input values
- **Docstring:** Documentation
- **Body:** Code to execute
- **Return:** Output value

## Common Patterns
```python
# No parameters
def get_time():
    return "10:30"

# Multiple parameters
def add(a, b):
    return a + b

# Default parameters
def power(x, n=2):
    return x ** n

# Variable arguments
def sum_all(*args):
    return sum(args)

# Keyword arguments
def describe(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")
```
