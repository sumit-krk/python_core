# Function Return Types

## Return Basics
```python
# Return single value
def add(a, b):
    return a + b

result = add(5, 3)      # 8

# No return (returns None)
def print_message(msg):
    print(msg)
    # Implicitly returns None
```

## Multiple Returns
```python
# Return tuple
def get_coordinates():
    return 10, 20

x, y = get_coordinates()

# Return multiple values
def calculate(a, b):
    return a + b, a - b, a * b
```

## Early Returns
```python
def find_max(numbers):
    if not numbers:
        return None  # Early return
    
    max_val = numbers[0]
    for num in numbers:
        if num > max_val:
            max_val = num
    return max_val
```

## Return Type Hints (Python 3.5+)
```python
def add(a: int, b: int) -> int:
    return a + b

def greet(name: str) -> str:
    return f"Hello, {name}"
```
