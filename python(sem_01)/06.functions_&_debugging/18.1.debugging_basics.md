# Debugging Basics

## Debugging Techniques

### 1. Print Debugging
```python
def calculate(a, b):
    print(f"Input: a={a}, b={b}")  # Debug output
    result = a + b
    print(f"Result: {result}")      # Debug output
    return result
```

### 2. assert Statement
```python
def divide(a, b):
    assert b != 0, "Cannot divide by zero"
    return a / b
```

### 3. Logging
```python
import logging
logging.basicConfig(level=logging.DEBUG)

def calculate(x):
    logging.debug(f"Calculating for x={x}")
    result = x * 2
    logging.debug(f"Result: {result}")
    return result
```

### 4. try-except
```python
try:
    result = 10 / 0
except ZeroDivisionError as e:
    print(f"Error: {e}")
```

### 5. pdb Debugger
```python
import pdb

def buggy_function():
    pdb.set_trace()  # Stop here
    result = 10 / 0
    return result
```

## Common Errors
- **SyntaxError:** Invalid syntax
- **NameError:** Undefined variable
- **TypeError:** Wrong data type
- **ValueError:** Wrong value
- **IndexError:** Index out of range
- **KeyError:** Dictionary key not found
- **ZeroDivisionError:** Division by zero
