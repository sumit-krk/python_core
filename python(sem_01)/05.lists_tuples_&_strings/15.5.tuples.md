# Tuples in Python

## Tuple Definition
A tuple is an ordered, immutable collection of items.

### Creating Tuples
```python
# Empty tuple
empty = ()

# Single element tuple (note the comma)
single = (1,)

# Multiple elements
pair = (1, 2)
triple = ("a", "b", "c")

# Without parentheses
coord = 1, 2, 3
```

## Tuple Characteristics
- **Immutable:** Cannot be changed after creation
- **Ordered:** Elements have fixed positions
- **Hashable:** Can be used as dictionary keys
- **Faster:** Slightly faster than lists
- **Memory:** Use less memory than lists

## Common Operations
```python
tpl = (1, 2, 3, 4, 5)

# Indexing
print(tpl[0])           # 1
print(tpl[-1])          # 5

# Slicing
print(tpl[1:3])         # (2, 3)

# Length
print(len(tpl))         # 5

# Unpacking
a, b, c = (1, 2, 3)
```

## When to Use Tuples
- Immutable data structures
- Dictionary keys
- Function return multiple values
- Protect data from modification
