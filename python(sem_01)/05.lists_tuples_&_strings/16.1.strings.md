# Strings in Python - Detailed

## String Definition
A string is an immutable sequence of characters.

### Creating Strings
```python
# Single quotes
s1 = 'hello'

# Double quotes
s2 = "hello"

# Triple quotes (multi-line)
s3 = """Hello
World"""

# Raw string
s4 = r"C:\Users\name"
```

## String Operations
```python
s = "Python"

# Indexing
print(s[0])             # 'P'
print(s[-1])            # 'n'

# Slicing
print(s[0:3])           # 'Pyt'

# Repetition
print(s * 2)            # 'PythonPython'

# Concatenation
print(s + " Programming")  # 'Python Programming'
```

## Common String Methods
- **upper/lower:** Change case
- **strip:** Remove whitespace
- **replace:** Replace substring
- **split:** Split into list
- **join:** Join list into string
- **find:** Find substring position
- **startswith/endswith:** Check prefix/suffix
