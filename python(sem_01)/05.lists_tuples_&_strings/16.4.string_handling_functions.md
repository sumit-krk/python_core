# String Handling Functions

## Built-in String Functions

### len() - String Length
```python
s = "Hello"
print(len(s))           # 5
```

### str() - Convert to String
```python
num = 42
s = str(num)            # "42"
```

### ord() - Character to ASCII
```python
print(ord('A'))         # 65
print(ord('a'))         # 97
```

### chr() - ASCII to Character
```python
print(chr(65))          # 'A'
print(chr(97))          # 'a'
```

### max() / min() - Character Range
```python
s = "Python"
print(max(s))           # 'y'
print(min(s))           # 'P'
```

### sorted() - Sort Characters
```python
s = "Python"
sorted(s)               # ['P', 'h', 'n', 'o', 't', 'y']
```

## String Validation

```python
s = "hello123"
s.isalpha()             # False (has digits)
s.isdigit()             # False (has letters)
s.isalnum()             # True (alphanumeric)
s.islower()             # True
```
