# String Input/Output

## Reading Strings
```python
# input() function reads string
name = input("Enter name: ")

# input() always returns string
age_str = input("Enter age: ")
age = int(age_str)  # Convert if needed
```

## Displaying Strings
```python
# print() function displays strings
print("Hello World")

# Multiple arguments
print("Name:", name, "Age:", age)

# String formatting
print(f"Hello {name}")
print("Value: {}".format(42))
```

## String Processing
```python
# Read and process
line = input("Enter text: ")
words = line.split()  # Split into words
print(f"Words: {words}")
print(f"Count: {len(words)}")
```
