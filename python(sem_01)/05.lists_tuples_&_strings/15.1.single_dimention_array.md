# Lists in Python

## List Definition
A list is an ordered, mutable collection of items.

### Creating Lists
```python
# Empty list
empty_list = []
empty_list = list()

# List with elements
numbers = [1, 2, 3, 4, 5]
mixed = [1, "hello", 3.14, True]

# Nested list
matrix = [[1, 2], [3, 4], [5, 6]]
```

## Common List Operations
- **append():** Add element to end
- **insert():** Add element at position
- **remove():** Remove first occurrence
- **pop():** Remove and return element
- **index():** Find first position
- **sort():** Sort in place
- **reverse():** Reverse in place

## List Methods
```python
lst = [1, 2, 3]
lst.append(4)           # [1, 2, 3, 4]
lst.insert(0, 0)        # [0, 1, 2, 3, 4]
lst.remove(2)           # [0, 1, 3, 4]
length = len(lst)       # 4
```

## Slicing
```python
lst = [0, 1, 2, 3, 4]
print(lst[0:3])     # [0, 1, 2]
print(lst[::-1])    # [4, 3, 2, 1, 0]
```
