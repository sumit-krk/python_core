# Multi-dimensional Lists (2D and 3D Arrays) in Python

## 2D Lists
```python
# 2D list (matrix)
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

# Access elements
print(matrix[0][0])     # 1
print(matrix[1][2])     # 6
print(matrix[2][1])     # 8
```

## 3D Lists
```python
# 3D list
cube = [
    [[1, 2], [3, 4]],
    [[5, 6], [7, 8]]
]

# Access element
print(cube[0][1][1])    # 4
```

## Iterating 2D Lists
```python
matrix = [[1, 2, 3], [4, 5, 6]]
for row in matrix:
    for element in row:
        print(element, end=" ")
    print()
```
