# Common List Pitfalls in Python

## Common Mistakes

### 1. Index Out of Range
```python
lst = [1, 2, 3]
print(lst[5])           # IndexError
# Use len() to check bounds
```

### 2. Modifying While Iterating
```python
lst = [1, 2, 3, 4, 5]
for item in lst:
    if item == 2:
        lst.remove(item)  # Dangerous!
# Use list comprehension instead
lst = [x for x in lst if x != 2]
```

### 3. Reference vs Copy
```python
original = [1, 2, 3]
copy = original          # Reference, not copy
copy.append(4)
print(original)          # [1, 2, 3, 4] - affected!

# Correct way
import copy
deep_copy = copy.deepcopy(original)
```

### 4. List vs Tuple Mutability
```python
lst = [1, 2, 3]
tpl = (1, 2, 3)
lst[0] = 10              # OK
tpl[0] = 10              # TypeError
```

### 5. Shallow vs Deep Copy
```python
original = [[1, 2], [3, 4]]
shallow = original.copy()
shallow[0][0] = 99       # Affects original!

deep = copy.deepcopy(original)
deep[0][0] = 99          # Original unaffected
```
