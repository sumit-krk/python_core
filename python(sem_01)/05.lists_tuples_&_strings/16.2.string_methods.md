# String Methods and Manipulation

## String Methods Summary

### Case Methods
```python
s = "Python Programming"
s.upper()               # PYTHON PROGRAMMING
s.lower()               # python programming
s.capitalize()          # Python programming
s.title()               # Python Programming
s.swapcase()            # pYTHON pROGRAMMING
```

### Search Methods
```python
s = "Hello World"
s.find("World")         # 6
s.index("o")            # 4
s.count("l")            # 3
s.startswith("Hello")   # True
s.endswith("ld")        # True
s.contains("World")     # True (use 'in' operator)
```

### Modification Methods
```python
s = "  Hello World  "
s.strip()               # "Hello World"
s.replace("World", "Python")  # "  Hello Python  "
s.split()               # ['Hello', 'World']
```

### Join Method
```python
words = ["Hello", "World", "Python"]
" ".join(words)         # "Hello World Python"
"-".join(words)         # "Hello-World-Python"
```

## String Formatting
```python
name = "Alice"
age = 30

# f-string
f"Name: {name}, Age: {age}"

# format method
"Name: {}, Age: {}".format(name, age)

# % formatting
"Name: %s, Age: %d" % (name, age)
```
