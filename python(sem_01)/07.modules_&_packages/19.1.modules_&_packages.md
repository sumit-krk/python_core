# Modules and Packages

## Modules
A module is a file containing Python definitions and statements.

### Importing Modules
```python
# Import entire module
import math
print(math.pi)

# Import specific function
from math import sqrt
print(sqrt(16))

# Import with alias
import numpy as np
```

## Creating Modules
```python
# Save as mymodule.py
def greet(name):
    return f"Hello, {name}"

def add(a, b):
    return a + b

# Use it
import mymodule
print(mymodule.greet("Alice"))
```

## Packages
A package is a directory with __init__.py file containing modules.

### Package Structure
```
mypackage/
    __init__.py
    module1.py
    module2.py
```

### Importing from Package
```python
from mypackage import module1
from mypackage.module1 import function1
```

## Standard Modules
- **math:** Mathematical functions
- **random:** Random numbers
- **datetime:** Date and time
- **os:** Operating system functions
- **sys:** System parameters
- **json:** JSON handling

For detailed module documentation, see comprehensive sections.
