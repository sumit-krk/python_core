# Python Programming - Semester 1 Syllabus

## Course Overview
This course introduces fundamental concepts of Python programming, covering basics to advanced topics.

## Learning Objectives
- Understand Python syntax and structure
- Work with data types and variables
- Implement control flow structures
- Use functions and modules effectively
- Understand Object-Oriented Programming
- File handling and I/O operations

## Course Outline

### Module 1: Introduction to Python
- History and importance of Python
- Python environment setup
- Basic syntax and structure
- Tokens and keywords
- Input/Output operations

### Module 2: Data Types
- Overview of data types
- Primitive data types (int, float, bool, str)
- Type conversion
- Strings and their methods

### Module 3: Operators & Expressions
- Arithmetic operators
- Relational operators
- Logical operators
- Membership and identity operators
- Operator precedence

### Module 4: Control Flow
- Conditional statements (if, elif, else)
- Switch-case (match-case in Python 3.10+)
- Looping constructs (for, while)
- Loop control (break, continue, pass)

### Module 5: Data Structures
- Lists and operations
- Tuples
- Strings and manipulation
- Common operations and pitfalls

### Module 6: Functions
- Function definition and calling
- Return types
- Parameters and arguments
- Recursion
- Debugging techniques

### Module 7: Modules & Packages
- Importing modules
- Creating modules and packages
- Namespace and scope
- Built-in functions

### Module 8: Object-Oriented Programming
- Classes and objects
- Inheritance
- Encapsulation
- Polymorphism

### Module 9: File Handling
- File I/O operations
- Working with text and binary files
- Standard library modules

### Module 10: Advanced Concepts
- Decorators
- Generators
- Lambda functions
- List comprehensions
