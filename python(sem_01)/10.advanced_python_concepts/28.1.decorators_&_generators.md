# Advanced Python Concepts

## Decorators
```python
def decorator(func):
    def wrapper(*args, **kwargs):
        print("Before")
        result = func(*args, **kwargs)
        print("After")
        return result
    return wrapper

@decorator
def greet():
    print("Hello")
```

## Generators
```python
def count_up(n):
    i = 0
    while i < n:
        yield i
        i += 1

for num in count_up(5):
    print(num)
```

## List Comprehensions
```python
# Create list from existing
squares = [x**2 for x in range(5)]

# With condition
evens = [x for x in range(10) if x % 2 == 0]

# Dictionary comprehension
squares_dict = {x: x**2 for x in range(5)}
```

## Lambda Functions
```python
# Anonymous functions
square = lambda x: x**2
print(square(5))        # 25

# With map
numbers = [1, 2, 3, 4]
squared = list(map(lambda x: x**2, numbers))
```

## Exception Handling
```python
try:
    result = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero")
except Exception as e:
    print(f"Error: {e}")
finally:
    print("Cleanup")
```
