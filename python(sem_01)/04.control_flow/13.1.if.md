# if Statement in Python

## Basic if Statement

### Syntax
```python
if condition:
    # Block of code
    statement1
    statement2
```

### Simple Example
```python
age = 18
if age >= 18:
    print("You are an adult")
```

### With Indentation
```python
# Indentation is mandatory in Python
if 5 > 3:
    print("Five is greater")
    print("This is inside if block")
print("This is outside if block")
```

---

## if with Multiple Statements

```python
x = 10
if x > 5:
    print("x is greater than 5")
    x = x + 1
    print(f"New value: {x}")
```

---

## Nested if Statements

```python
age = 20
score = 85

if age >= 18:
    print("Adult")
    if score >= 80:
        print("High score")
    else:
        print("Need improvement")
```

## Practical Examples

### Example 1: Grade Check
```python
score = 75
if score >= 90:
    print("Grade: A")
if score >= 80:
    print("Good performance")
if score >= 70:
    print("Passed")
```

### Example 2: Range Check
```python
num = 50
if num >= 0:
    if num <= 100:
        print("Valid number")
```

### Example 3: User Validation
```python
username = input("Enter username: ")
password = input("Enter password: ")

if username == "admin":
    if password == "secure123":
        print("Login successful")
        print("Welcome to dashboard")
```

## Common Mistakes

### Forgetting Colon
```python
# Wrong
if x > 5
    print("x is greater")

# Correct
if x > 5:
    print("x is greater")
```

### Incorrect Indentation
```python
# Wrong
if x > 5:
print("not indented")  # IndentationError

# Correct
if x > 5:
    print("properly indented")
```

### Using = instead of ==
```python
# Wrong
if x = 5:           # SyntaxError
    print("x is 5")

# Correct
if x == 5:
    print("x is 5")
```

---

## Summary

- **if statement:** Executes block if condition is True
- **Indentation:** Mandatory and defines code block
- **Nested if:** Multiple levels of conditions
- **Colon (:):** Required after condition
- **Use cases:** Branching logic, validation, control flow
