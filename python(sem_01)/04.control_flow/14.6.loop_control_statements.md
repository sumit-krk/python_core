# Loop Control Statements (break, continue, pass)

## Summary of Loop Control

This topic covers:
- **break:** Terminate loop immediately
- **continue:** Skip to next iteration
- **pass:** Placeholder for future code
- **Nested loops:** Control flow in complex structures

### When to Use Each

| Statement | Use Case |
|-----------|----------|
| break | Exit loop early (found target, error) |
| continue | Skip current iteration (filter, skip invalid) |
| pass | Placeholder, no operation needed |

### Best Practices

1. Keep loop logic simple
2. Avoid deep nesting
3. Use meaningful conditions
4. Document complex loop control
5. Test edge cases

---

## Key Takeaways

- **break:** Most common for early exit
- **continue:** Most common for skipping items
- **pass:** Least common, mainly for placeholders
- **Readability:** Simple logic > clever tricks
- **Performance:** Consider complexity of nested loops

---

## Quick Reference

```python
# break
for i in range(10):
    if i == 5:
        break  # Exit immediately

# continue
for i in range(10):
    if i == 5:
        continue  # Skip, go to next

# pass
for i in range(10):
    pass  # Do nothing

# In nested loops
for i in range(3):
    for j in range(3):
        if condition:
            break  # Exits inner loop only
```
