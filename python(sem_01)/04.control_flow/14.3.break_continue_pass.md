# break, continue, and pass Statements

## break Statement

### Purpose
Exits/terminates the current loop immediately.

### Syntax
```python
break
```

### Examples
```python
# Exit for loop
for i in range(10):
    if i == 5:
        break
    print(i)  # 0 1 2 3 4

# Exit while loop
while True:
    user_input = input("Enter 'quit' to exit: ")
    if user_input == "quit":
        break
    print(f"You entered: {user_input}")
```

### Nested Loop break
```python
# break only exits inner loop
for i in range(3):
    for j in range(3):
        if j == 1:
            break
        print(f"{i},{j}", end=" ")
    print()

# Output:
# 0,0
# 1,0
# 2,0
```

## continue Statement

### Purpose
Skips current iteration, continues with next iteration.

### Syntax
```python
continue
```

### Examples
```python
# Skip even numbers
for i in range(10):
    if i % 2 == 0:
        continue
    print(i)  # 1 3 5 7 9

# Skip specific items
for item in ["apple", "banana", "orange"]:
    if item == "banana":
        continue
    print(item)  # apple orange
```

### Nested Loop continue
```python
for i in range(3):
    for j in range(3):
        if j == 1:
            continue
        print(f"{i},{j}", end=" ")
    print()

# Output:
# 0,0 0,2
# 1,0 1,2
# 2,0 2,2
```

## pass Statement

### Purpose
Does nothing; placeholder for future code.

### Syntax
```python
pass
```

### Uses
```python
# Empty function
def future_function():
    pass

# Empty class
class MyClass:
    pass

# Empty loop
for i in range(5):
    pass

# Placeholder in if statement
if x > 5:
    pass  # TODO: implement this
else:
    print("x is not greater than 5")
```

## Practical Examples

### Example 1: Search with break
```python
numbers = [1, 5, 3, 8, 2, 9]
target = 8
found = False

for num in numbers:
    if num == target:
        found = True
        break

if found:
    print("Target found")
else:
    print("Target not found")
```

### Example 2: Skip Invalid Data
```python
data = [1, -2, 3, -4, 5]
for value in data:
    if value < 0:
        continue  # Skip negative values
    print(f"Processing: {value}")
```

### Example 3: Nested Loop with break
```python
# Find first occurrence in 2D list
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
target = 5
found = False

for row in matrix:
    for val in row:
        if val == target:
            found = True
            break
    if found:
        break

print(f"Found {target}" if found else f"{target} not found")
```

## Common Patterns

### Pattern 1: Find and Exit
```python
for item in items:
    if condition(item):
        print(f"Found: {item}")
        break
```

### Pattern 2: Filter Items
```python
for item in items:
    if should_skip(item):
        continue
    process(item)
```

### Pattern 3: Placeholder
```python
try:
    dangerous_operation()
except Exception:
    pass  # TODO: handle error
```

## Loop Control Flow

### break and continue in for-else
```python
# With break (else doesn't execute)
for i in range(5):
    if i == 3:
        break
else:
    print("Completed")  # Not printed

# With continue (else executes)
for i in range(5):
    if i == 3:
        continue
else:
    print("Completed")  # Printed

# Without break/continue
for i in range(5):
    pass
else:
    print("Completed")  # Printed
```

## Practical Use Cases

### Example 1: Input Validation Loop
```python
while True:
    age = input("Enter age (1-120): ")
    try:
        age = int(age)
        if 1 <= age <= 120:
            print(f"Valid age: {age}")
            break  # Exit on success
        else:
            print("Age out of range")
            continue  # Ask again
    except ValueError:
        print("Please enter a number")
        continue  # Ask again
```

### Example 2: Menu System
```python
while True:
    print("\n1. Start  2. Stop  3. Exit")
    choice = input("Choose: ")
    
    if choice == "1":
        print("Starting...")
    elif choice == "2":
        print("Stopping...")
    elif choice == "3":
        print("Goodbye!")
        break  # Exit
    else:
        print("Invalid choice")
        continue  # Ask again
```

### Example 3: Data Processing
```python
for record in records:
    if not validate(record):
        continue  # Skip invalid records
    
    if is_duplicate(record):
        continue  # Skip duplicates
    
    if reached_limit():
        break  # Stop processing
    
    process(record)
```

## Best Practices

1. **Use break** to exit when condition is met
2. **Use continue** to skip current iteration
3. **Use pass** only as placeholder
4. **Avoid deep nesting** with break/continue
5. **Keep code readable** - don't overuse these statements

---

## Summary

- **break:** Exit loop immediately
- **continue:** Skip current iteration
- **pass:** Placeholder (does nothing)
- **for-else:** else skipped if break occurs
- **Practical:** Use for validation, filtering, searching
