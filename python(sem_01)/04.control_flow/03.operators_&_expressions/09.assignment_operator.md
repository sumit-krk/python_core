# Assignment Operators in Python

## Basic Assignment Operator

### Assignment (=)
```python
# Simple assignment
x = 10
name = "Python"
flag = True

# Multiple assignment
a = b = c = 10  # All variables assigned to 10

# Unpacking assignment
x, y, z = 1, 2, 3
print(x, y, z)  # 1 2 3

# Swapping
a = 5
b = 10
a, b = b, a
print(a, b)     # 10 5
```

---

## Augmented Assignment Operators

These combine operation and assignment:

### Addition Assignment (+=)
```python
x = 10
x += 5          # x = x + 5
print(x)        # 15

# With strings
text = "Hello"
text += " World"
print(text)     # "Hello World"

# With lists
lst = [1, 2]
lst += [3, 4]
print(lst)      # [1, 2, 3, 4]
```

### Subtraction Assignment (-=)
```python
x = 10
x -= 3          # x = x - 3
print(x)        # 7
```

### Multiplication Assignment (*=)
```python
x = 5
x *= 2          # x = x * 2
print(x)        # 10

# String repetition
text = "ab"
text *= 3       # text = text * 3
print(text)     # "ababab"
```

### Division Assignment (/=)
```python
x = 20
x /= 4          # x = x / 4
print(x)        # 5.0
```

### Floor Division Assignment (//=)
```python
x = 20
x //= 3         # x = x // 3
print(x)        # 6
```

### Modulo Assignment (%=)
```python
x = 20
x %= 3          # x = x % 3
print(x)        # 2
```

### Exponentiation Assignment (**=)
```python
x = 2
x **= 3         # x = x ** 3
print(x)        # 8
```

## Practical Examples

### Example 1: Accumulator Pattern
```python
# Sum numbers
total = 0
numbers = [10, 20, 30, 40]

for num in numbers:
    total += num

print(total)    # 100
```

### Example 2: Counter
```python
count = 0
while count < 5:
    print(count)
    count += 1      # Increment counter
```

### Example 3: Building Strings
```python
message = ""
words = ["Hello", "World", "Python"]

for word in words:
    message += word + " "

print(message)  # "Hello World Python "
```

### Example 4: Matrix Scaling
```python
# Scale a value repeatedly
value = 1
for _ in range(3):
    value *= 2
print(value)    # 8 (1 * 2 * 2 * 2)
```

## Chained Assignment

```python
# Assign same value to multiple variables
a = b = c = 100
print(a, b, c)  # 100 100 100

# Tuple unpacking
x, y = 10, 20
print(x, y)     # 10 20

# Extended unpacking
a, *b, c = [1, 2, 3, 4, 5]
print(a)        # 1
print(b)        # [2, 3, 4]
print(c)        # 5
```

## Common Mistakes

### Forgetting the Operator
```python
# Wrong
x + 5  # Just evaluates, doesn't assign

# Correct
x += 5  # Assigns result back to x
```

### Confusing = with ==
```python
# Wrong - assignment in condition
if x = 5:       # SyntaxError
    pass

# Correct - comparison
if x == 5:
    pass
```

### Modifying During Assignment
```python
# This works
x = 10
x += 5          # x becomes 15

# But this doesn't work
y = y + 5       # If y is not defined, NameError

# For undefined variables
counter = 0     # Initialize first
counter += 1    # Then augment
```

## Performance Considerations

### Augmented Assignment vs Regular Assignment
```python
# Augmented assignment (often more efficient)
x += 5          # May modify in-place for mutable objects

# Regular assignment (always creates new binding)
x = x + 5       # Creates new object

# For large lists, difference is noticeable
lst = [1, 2, 3]
lst += [4, 5]   # In-place extension (efficient)

lst = lst + [6, 7]  # Creates new list (less efficient)
```

## Summary

- **= (Assignment):** Assigns value to variable
- **+= through **=:** Augmented operators combine operation with assignment
- **Multiple assignment:** Assign same value to multiple variables
- **Unpacking:** Unpack collections to multiple variables
- **Swapping:** Easy swapping using tuple unpacking
- **Efficiency:** Augmented assignment may be more efficient for mutable objects
