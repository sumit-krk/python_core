# Relational (Comparison) Operators in Python

## Comparison Operators

### 1. Equal to (==)
```python
a = 10
b = 10
print(a == b)       # True

x = 5
y = 3
print(x == y)       # False

# String comparison
name1 = "Alice"
name2 = "Alice"
print(name1 == name2)   # True
```

### 2. Not Equal to (!=)
```python
a = 10
b = 5
print(a != b)       # True

x = "Hello"
y = "Hello"
print(x != y)       # False
```

### 3. Greater Than (>)
```python
a = 10
b = 5
print(a > b)        # True
print(b > a)        # False

# String comparison (lexicographical)
print("Apple" > "Banana")   # False
print("Zebra" > "Apple")    # True
```

### 4. Less Than (<)
```python
a = 5
b = 10
print(a < b)        # True
print(b < a)        # False

# Character comparison (ASCII values)
print('A' < 'B')    # True
print('a' < 'A')    # False (lowercase > uppercase)
```

### 5. Greater Than or Equal to (>=)
```python
a = 10
b = 10
print(a >= b)       # True

x = 5
print(x >= 10)      # False
```

### 6. Less Than or Equal to (<=)
```python
a = 5
b = 10
print(a <= b)       # True

x = 10
print(x <= 10)      # True
```

## Chained Comparisons

```python
x = 5
print(1 < x < 10)   # True (equivalent to 1 < x and x < 10)
print(10 > x > 0)   # True

# Practical example
score = 75
if 0 <= score <= 100:
    print("Valid score")
```

## Comparison with Different Types

### Integer vs Float
```python
print(10 == 10.0)   # True
print(10 > 9.9)     # True
```

### String Comparison
```python
# Lexicographical order (dictionary order)
print("apple" < "banana")   # True
print("Zebra" > "apple")    # False (uppercase < lowercase)

# Case-sensitive
print("abc" < "ABC")        # False
```

### List Comparison
```python
list1 = [1, 2, 3]
list2 = [1, 2, 3]
print(list1 == list2)       # True

list3 = [1, 2, 4]
print(list1 < list3)        # True (lexicographical)
```

## Using Comparisons in Conditions

### if Statements
```python
age = 18
if age >= 18:
    print("Adult")
else:
    print("Minor")
```

### Multiple Conditions
```python
score = 75
subject = "Math"

if score >= 90 and subject == "Math":
    print("Excellent in Math")
elif score >= 80:
    print("Good")
else:
    print("Average")
```

## Common Mistakes

### Equality vs Assignment
```python
# Wrong: = is assignment
if x = 5:           # SyntaxError
    print("x is 5")

# Correct: == is comparison
if x == 5:
    print("x is 5")
```

### Comparing with is vs ==
```python
# == compares values
print(10 == 10.0)   # True

# is compares identity (memory location)
print(10 is 10.0)   # False
print(10 is 10)     # Usually True (Python caches small integers)

a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)       # True (same content)
print(a is b)       # False (different objects)
```

### String Comparison Case Sensitivity
```python
# Case matters
print("Apple" == "apple")   # False
print("Apple".lower() == "apple".lower())  # True
```

|-----------|--------|
| 5 == 5 | True |

| 5 > 3 | True |
| 5 < 3 | False |
| 5 >= 5 | True |
| 5 <= 5 | True |

## Practical Examples

### Example 1: Age Validation
```python
age = 25
if age >= 18 and age <= 65:
    print("Working age")
elif age < 18:
    print("Minor")
else:
    print("Senior")
```

### Example 2: Grade Assignment
```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"Grade: {grade}")
```

### Example 3: Range Checking
```python
num = 42
lower = 1
upper = 100

if lower <= num <= upper:
    print(f"{num} is in range")
else:
    print(f"{num} is out of range")
```

---

## Summary

- **== (Equal):** Value equality
- **!= (Not equal):** Value inequality
- **> (Greater than):** Left is larger
- **< (Less than):** Left is smaller
- **>= (Greater or equal):** Left is larger or equal
- **<= (Less or equal):** Left is smaller or equal
- **Chaining:** Combine multiple comparisons (e.g., 1 < x < 10)
- **is vs ==:** Use == for value comparison, is for identity
- **Result:** Always True or False
