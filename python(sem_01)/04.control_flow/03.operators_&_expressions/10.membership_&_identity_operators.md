# Membership and Identity Operators in Python

## Membership Operators

### in Operator
```python
# Check if element exists in sequence
lst = [1, 2, 3, 4, 5]
print(3 in lst)         # True
print(10 in lst)        # False

# Check if substring exists
text = "Hello, World!"
print("World" in text)  # True
print("xyz" in text)    # False

# Check key in dictionary
person = {"name": "John", "age": 30}
print("name" in person)  # True
print("address" in person)  # False

# Check element in tuple
colors = ("red", "green", "blue")
print("red" in colors)  # True
```

### not in Operator
```python
lst = [1, 2, 3, 4, 5]
print(10 not in lst)    # True
print(3 not in lst)     # False

# String check
word = "Python"
print("x" not in word)  # True
print("P" not in word)  # False

# Dictionary check
data = {"a": 1, "b": 2}
print("c" not in data)  # True
```

## Identity Operators

### is Operator
```python
# Check if two variables reference the same object
a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a is b)   # False (different objects)
print(a is c)   # True (same object)

# With small integers (cached by Python)
x = 10
y = 10
print(x is y)   # True (same object - Python caches small integers)

# With larger integers
x = 1000
y = 1000
print(x is y)   # False (different objects)

# With strings
s1 = "hello"
s2 = "hello"
print(s1 is s2) # Likely True (string interning)
```

### is not Operator
```python
a = [1, 2, 3]
b = [1, 2, 3]

print(a is not b)   # True (different objects)
print(a is not a)   # False (same object)

# With None
x = None
print(x is None)    # True
print(x is not None)  # False
```

## Difference between == and is

### == (Equality)
```python
# Compares values
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)       # True (same content)

x = 10
y = 10.0
print(x == y)       # True (values are equal)
```

### is (Identity)
```python
# Compares memory location
a = [1, 2, 3]
b = [1, 2, 3]
print(a is b)       # False (different objects)

x = 10
y = 10.0
print(x is y)       # False (different objects)
```

### Comparison Table

| Code | == Result | is Result |
|------|-----------|-----------|
| [1,2] == [1,2] | True | False |
| 10 == 10.0 | True | False |
| a = [1]; b = a; a == b | True | True |
| None == None | True | True |
| None is None | - | True |

## Using Membership Operators

### Example 1: Check Valid Input
```python
valid_options = ["A", "B", "C"]
user_choice = input("Choose A, B, or C: ")

if user_choice in valid_options:
    print("Valid choice")
else:
    print("Invalid choice")
```

### Example 2: Check Forbidden Words
```python
forbidden = ["admin", "root", "password"]
username = input("Enter username: ")

if username.lower() in forbidden:
    print("Username not allowed")
else:
    print("Username accepted")
```

### Example 3: Search in String
```python
text = "Python is great"
search = "great"

if search in text:
    print(f"'{search}' found in text")
    index = text.find(search)
    print(f"Position: {index}")
```

### Example 4: Check Dictionary Keys
```python
student = {"name": "John", "age": 20, "grade": "A"}

if "name" in student:
    print(f"Name: {student['name']}")

if "email" not in student:
    print("Email not found")
```

## Using Identity Operators

### Example 1: Singleton Pattern (None Check)
```python
x = None
if x is None:
    print("x is not initialized")

if x is not None:
    print("x has a value")
```

### Example 2: Object Reference Check
```python
# Check if same object
original = [1, 2, 3]
reference = original
copy = original.copy()

if reference is original:
    print("Same object")

if copy is not original:
    print("Different copy")
```

### Example 3: True/False Check (Advanced)
```python
# Usually avoid this - use "if x:" instead
x = True
if x is True:       # Not recommended
    pass

if x:               # Better practice
    pass
```

## Practical Combinations

### Combining Membership and Identity
```python
# Check if None in list
values = [1, 2, None, 4, 5]
if None in values:
    print("Contains None")

# Check for specific values
numbers = [10, 20, 30]
if 20 in numbers and len(numbers) is not None:
    print("Found 20 in list")
```

### With Conditionals
```python
# Validate user input
valid_commands = ["help", "exit", "status"]
command = input("Enter command: ")

if command not in valid_commands:
    print("Unknown command")

# Check for None values in processing
data = get_data()
if data is not None and len(data) > 0:
    process(data)
```

## Common Mistakes

### Using is with Strings/Numbers
```python
# Don't rely on is for strings beyond interning
s1 = "hello"
s2 = "".join(["h", "e", "l", "l", "o"])
print(s1 is s2)     # Might be False

# Use == instead
print(s1 == s2)     # True
```

### Using is with Lists/Dicts
```python
# Wrong
if my_list is [1, 2, 3]:  # Won't work as expected
    pass

# Correct
if my_list == [1, 2, 3]:  # Correct
    pass
```

### Forgetting to check None properly
```python
# Can cause errors
value = None
if value and value > 0:   # Better
    pass

if value is not None and value > 0:  # Most explicit
    pass
```

## Summary

- **in / not in:** Check membership in sequences and collections
- **is / is not:** Check if variables reference the same object (identity)
- **== vs is:** Use == for value comparison, is for identity check
- **Common use:** Check for None using "is None", check list membership with "in"
- **Performance:** Identity checks are faster than equality checks
- **Best practice:** Use == for data comparison, is for None checks
