# Logical Operators in Python

## Logical Operators

### 1. and Operator
```python
# Returns True only if both conditions are True
a = 10
b = 20

print(a < 20 and b > 10)        # True
print(a < 5 and b > 10)         # False

# Multiple conditions
age = 25
income = 50000
if age >= 18 and income > 30000:
    print("Eligible for loan")
```

### 2. or Operator
```python
# Returns True if at least one condition is True
a = 10
b = 20

print(a > 15 or b > 15)         # True
print(a < 5 or b < 5)           # False

# Practical example
day = "Saturday"
if day == "Saturday" or day == "Sunday":
    print("Weekend")
```

### 3. not Operator
```python
# Reverses the boolean value
a = True
b = False

print(not a)                    # False
print(not b)                    # True

# With conditions
x = 10
if not x < 5:
    print("x is not less than 5")
```

## Operator Precedence

Order of evaluation:
1. `not`
2. `and`
3. `or`

### Examples
```python
# Without parentheses (follows precedence)
result = True or False and False
# Evaluated as: True or (False and False) = True or False = True

# With parentheses (for clarity)
result = (True or False) and False  # False

# Always use parentheses for complex expressions
result = (x > 5 and x < 10) or (x > 20)
```

## Short-Circuit Evaluation

Python stops evaluating when result is determined:

### and Short-Circuit
```python
# If first is False, second is not evaluated
x = 0
result = x > 0 and 10 / x  # No division error (x > 0 is False)

# First is True, second is evaluated
x = 5
result = x > 0 and 10 / x  # 2.0
```

### or Short-Circuit
```python
# If first is True, second is not evaluated
x = 0
result = x > 0 or True  # True (second not evaluated)

# First is False, second is evaluated
x = 0
result = x > 0 or x == 0  # True
```

## Combining Logical Operators

```python
# Multiple conditions with different operators
age = 25
score = 85

# Age between 18-65 AND score >= 80
if 18 <= age <= 65 and score >= 80:
    print("Qualified")

# Age < 18 OR (age > 65 AND has experience)
has_experience = True
if age < 18 or (age > 65 and has_experience):
    print("Special consideration")

# NOT (age < 18)
if not age < 18:
    print("At least 18 years old")
```

## Practical Examples

### Example 1: User Authentication
```python
username = "john"
password = "secure123"
attempts = 2

if (username == "john" and password == "secure123") and attempts < 3:
    print("Login successful")
else:
    print("Login failed")
```

### Example 2: Grade Eligibility
```python
attendance = 85
score = 70
participation = True

if attendance >= 75 and score >= 60 and participation:
    print("Pass")
else:
    print("Fail - check conditions")
```

### Example 3: Range Checking
```python
num = 50

# Check if number is in specific ranges
if (0 < num < 50) or (100 < num < 150):
    print("In valid range")
else:
    print("Out of range")

# Using not
if not (num < 0 or num > 200):
    print("Within bounds")
```

### Example 4: Validation
```python
email = "user@example.com"
age = 25

if "@" in email and "." in email and age >= 18:
    print("Valid registration")
else:
    print("Invalid registration")
```

## Truthy and Falsy Values

### Falsy Values
```python
print(bool(0))          # False
print(bool(0.0))        # False
print(bool(""))         # False
print(bool([]))         # False
print(bool(()))         # False
print(bool({}))         # False
print(bool(None))       # False
```

### Truthy Values
```python
print(bool(1))          # True
print(bool("text"))     # True
print(bool([1, 2]))     # True
print(bool((1, 2)))     # True
print(bool({'a': 1}))   # True
```

### Using Truthy/Falsy in Conditions
```python
lst = [1, 2, 3]
if lst:                 # True if non-empty
    print("List has items")

name = ""
if not name:            # True if empty string
    print("Name is empty")
```

## Common Mistakes

### Using = instead of ==
```python
# Wrong
if x = 5 and y > 10:    # SyntaxError
    pass

# Correct
if x == 5 and y > 10:
    pass
```

### Wrong Operator Precedence
```python
# Without parentheses (may not work as intended)
if x > 5 and y > 10 or z == 0:
    pass

# Clear with parentheses
if (x > 5 and y > 10) or (z == 0):
    pass
```

### Misunderstanding and/or
```python
# and returns False if first is False
result = False and True  # False

# or returns True if first is True
result = True or False   # True

# They return boolean values, not other values
# (though in some cases they return the actual value)
print(5 and 10)         # 10 (returns last value if all truthy)
print(0 or 5)           # 5 (returns first truthy value)
```

## Summary

- **and:** True if both conditions are True
- **or:** True if at least one condition is True
- **not:** Reverses the boolean value
- **Precedence:** not > and > or
- **Short-circuit:** Python stops evaluating when result is certain
- **Combine:** Use parentheses for complex expressions
- **Truthy/Falsy:** Empty/zero values are falsy, others are truthy
