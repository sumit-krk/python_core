# Operator Precedence & Associativity in Python

## Operator Precedence

Operators are evaluated from highest to lowest precedence:

### Precedence Table (Highest to Lowest)

| Priority | Operator | Description | Associativity |
|----------|----------|-------------|----------------|
| 1 | () | Parentheses | Left-to-right |
| 2 | [] | Indexing, slicing | Left-to-right |
| 3 | ** | Exponentiation | Right-to-left |
| 4 | +x, -x, ~x | Unary plus, minus, bitwise NOT | Right-to-left |
| 5 | *, /, //, % | Multiplication, division, modulo | Left-to-right |
| 6 | +, - | Addition, subtraction | Left-to-right |
| 7 | <<, >> | Bitwise shifts | Left-to-right |
| 8 | & | Bitwise AND | Left-to-right |
| 9 | ^ | Bitwise XOR | Left-to-right |
| 10 | \| | Bitwise OR | Left-to-right |
| 11 | ==, !=, <, <=, >, >=, is, in, not | Comparisons | Left-to-right |
| 12 | not | Logical NOT | Right-to-left |
| 13 | and | Logical AND | Left-to-right |
| 14 | or | Logical OR | Left-to-right |
| 15 | = | Assignment | Right-to-left |

---

## Exponentiation Associativity

### Right-to-Left Associativity
```python
# Exponentiation is right-associative
result = 2 ** 3 ** 2
# Evaluated as: 2 ** (3 ** 2) = 2 ** 9 = 512
print(result)       # 512

# NOT as (2 ** 3) ** 2 = 8 ** 2 = 64

# Verification
print(2 ** (3 ** 2))    # 512
print((2 ** 3) ** 2)    # 64
```

---

## Arithmetic Operator Precedence

```python
# Exponentiation first
result = 2 + 3 ** 2    # 2 + 9 = 11
print(result)

# Multiplication before addition
result = 2 + 3 * 4     # 2 + 12 = 14
print(result)

# Left-to-right for same precedence
result = 10 - 5 - 2    # (10 - 5) - 2 = 3
print(result)

# NOT right-to-left
result = 10 - 5 - 2    # NOT 10 - (5 - 2) = 7
```

---

## Bitwise Operator Precedence

```python
# AND has higher precedence than OR
result = True or False and False
# Evaluated as: True or (False and False) = True
print(result)       # True

# Bitwise & has higher precedence than |
result = 5 | 3 & 2  # 5 | (3 & 2) = 5 | 2 = 7
print(result)

# Shifts have lower precedence than arithmetic
result = 2 + 3 << 1 # (2 + 3) << 1 = 5 << 1 = 10
print(result)
```

---

## Comparison and Logical Operators

```python
# Comparisons have higher precedence than logical operators
x = 5
result = x > 3 and x < 10
# Evaluated as: (x > 3) and (x < 10) = True and True = True
print(result)

# Logical NOT highest among logical operators
result = not x > 3      # NOT(x > 3) - be careful!
print(result)           # False

# Use parentheses for clarity
result = not (x > 3)    # Better
```

## Using Parentheses

### Example 1: Force Order of Evaluation
```python
# Without parentheses (follows precedence)
result = 2 + 3 * 4          # 14

# With parentheses (different order)
result = (2 + 3) * 4        # 20

# Complex expression
result = (10 - 5) * 2 + 3   # 13
```

### Example 2: Multiple Operations
```python
# Unclear without parentheses
result = 10 + 5 * 2 - 3 / 1  # 17

# With parentheses (clear intent)
result = ((10 + (5 * 2)) - (3 / 1))  # 17
```

## Practical Examples

### Example 1: Mathematical Expression
```python
# Calculate: (10 + 5) * 2^2 / 4
result = (10 + 5) * 2 ** 2 / 4
print(result)   # 15.0

# Breaking it down:
# (10 + 5) = 15
# 2 ** 2 = 4
# 15 * 4 = 60
# 60 / 4 = 15.0
```

### Example 2: Logical Expression
```python
# Check multiple conditions
age = 25
score = 85

if age >= 18 and score > 80 and not score > 100:
    print("Pass")
```

### Example 3: Bitwise and Comparison
```python
# Careful with precedence
num = 5
if num & 1 == 1:            # Wrong: evaluated as num & (1 == 1)
    print("Odd")

if (num & 1) == 1:          # Correct: use parentheses
    print("Odd")
```

## Associativity Examples

### Left-to-Right Associativity
```python
# Subtraction is left-associative
result = 10 - 5 - 2
# Evaluated as: (10 - 5) - 2 = 5 - 2 = 3
print(result)   # 3

# NOT right-to-left
result = 10 - (5 - 2)       # 7
```

### Right-to-Left Associativity
```python
# Exponentiation is right-associative
result = 2 ** 3 ** 2
# Evaluated as: 2 ** (3 ** 2) = 2 ** 9 = 512
print(result)   # 512

# Assignment is right-associative
a = b = c = 10
# Evaluated as: a = (b = (c = 10))
print(a, b, c)  # 10 10 10
```

## Best Practices

1. **Always use parentheses** for clarity, even if not strictly necessary
2. **Group related operations** together with parentheses
3. **Comment complex expressions** to explain intent
4. **Break down** complex calculations into simpler steps
5. **Test** to verify order of evaluation

---

## Common Mistakes

### Missing Parentheses
```python
# Wrong - might not work as intended
if x > 5 and y < 10 and z == 0:
    pass

# Better - clear intent
if (x > 5) and (y < 10) and (z == 0):
    pass
```

### Operator Precedence Confusion
```python
# Confusing
result = 1 + 2 * 3          # 7, not 9

# Clear
result = 1 + (2 * 3)        # 7
result = (1 + 2) * 3        # 9
```

### Bitwise Operations
```python
# Easy to mistake with logical operators
result = 5 and 3             # 3 (logical)
result = 5 & 3              # 1 (bitwise)
```

---

## Summary

- **Parentheses** have highest precedence
- **Exponentiation** is right-to-left associative
- **Other operators** mostly left-to-right associative
- **Always use parentheses** for complex expressions
- **Refer to precedence table** when unsure
- **Comment** complex expressions
