# Bitwise Operators in Python

## Bitwise Operators

### 1. AND (&)
```python
# Bitwise AND
a = 5        # Binary: 0101
b = 3        # Binary: 0011
result = a & b  # 0001 = 1
print(result)   # 1

# Example
print(12 & 10)  # Binary: 1100 & 1010 = 1000 = 8
```

### 2. OR (|)
```python
# Bitwise OR
a = 5        # Binary: 0101
b = 3        # Binary: 0011
result = a | b  # 0111 = 7
print(result)   # 7

# Example
print(12 | 10)  # Binary: 1100 | 1010 = 1110 = 14
```

### 3. XOR (^)
```python
# Bitwise XOR (exclusive OR)
a = 5        # Binary: 0101
b = 3        # Binary: 0011
result = a ^ b  # 0110 = 6
print(result)   # 6

# Example
print(12 ^ 10)  # Binary: 1100 ^ 1010 = 0110 = 6
```

### 4. NOT (~)
```python
# Bitwise NOT (inverts all bits)
a = 5        # Binary: 0101
result = ~a     # Inverts to -(a+1) = -6
print(result)   # -6

# Example
print(~12)      # -(12 + 1) = -13
```

### 5. Left Shift (<<)
```python
# Left shift (multiply by 2^n)
a = 5           # Binary: 0101
result = a << 1 # 1010 = 10
print(result)   # 10

# Left shift by 2 (multiply by 4)
print(5 << 2)   # 20 (5 * 4)

# General: a << n = a * 2^n
print(3 << 3)   # 24 (3 * 8)
```

### 6. Right Shift (>>)
```python
# Right shift (divide by 2^n)
a = 20          # Binary: 10100
result = a >> 1 # 01010 = 10
print(result)   # 10

# Right shift by 2 (divide by 4)
print(20 >> 2)  # 5 (20 / 4)

# General: a >> n = a / 2^n (floor division)
print(24 >> 3)  # 3 (24 / 8)
```

## Binary Representation

### Converting to Binary
```python
# Decimal to binary
num = 10
binary = bin(num)       # '0b1010'
binary_str = bin(num)[2:]  # '1010'

# Binary to decimal
binary_val = 0b1010     # 10
binary_str = "1010"
decimal = int(binary_str, 2)  # 10

# Other bases
print(hex(255))         # '0xff' (hexadecimal)
print(oct(64))          # '0o100' (octal)
```

## Practical Applications

### Example 1: Check if Number is Power of 2
```python
def is_power_of_2(n):
    return n > 0 and (n & (n - 1)) == 0

print(is_power_of_2(8))     # True (1000)
print(is_power_of_2(10))    # False (1010)
```

### Example 2: Count Set Bits
```python
def count_bits(n):
    count = 0
    while n:
        count += n & 1      # Check if last bit is 1
        n >>= 1             # Right shift by 1
    return count

print(count_bits(10))   # 2 (binary: 1010)
```

### Example 3: Fast Multiplication/Division
```python
# Multiply by 8 (equivalent to * 2^3)
result = 5 << 3         # 40

# Divide by 4 (equivalent to / 2^2)
result = 20 >> 2        # 5
```

### Example 4: Toggle a Bit
```python
# XOR to toggle
value = 0b1100
bit_position = 2
toggled = value ^ (1 << bit_position)
print(bin(toggled))     # 0b1000
```

### Example 5: Set/Clear Bits
```python
# Set a bit
value = 0b1000
bit_position = 1
set_bit = value | (1 << bit_position)
print(bin(set_bit))     # 0b1010

# Clear a bit
value = 0b1011
bit_position = 1
clear_bit = value & ~(1 << bit_position)
print(bin(clear_bit))   # 0b1001
```

```python

x &= 3      # x = x & 3
print(x)    # 1

x = 5
x |= 3      # x = x | 3
print(x)    # 7

x = 5
x ^= 3      # x = x ^ 3
print(x)    # 6

x = 5
x <<= 1     # x = x << 1
print(x)    # 10

x = 20
x >>= 2     # x = x >> 2
print(x)    # 5
```

## Common Use Cases

1. **Flags/Permissions:** Store multiple boolean flags in single integer
2. **Optimization:** Fast operations for low-level programming
3. **Cryptography:** XOR operations for encryption
4. **Graphics:** Pixel manipulation
5. **Networking:** IP address manipulation
6. **Performance-critical code:** Bitwise ops are faster than arithmetic

## Common Mistakes

### Operator Precedence
```python
# Bitwise & has lower precedence than comparison
# Wrong interpretation
if x & 1 == 1:      # Evaluated as: x & (1 == 1)
    pass

# Correct
if (x & 1) == 1:    # Use parentheses
    pass
```

### Negative Numbers
```python
# NOT operation on negative numbers
print(~5)           # -6 (two's complement)
print(~-1)          # 0
```

---

## Summary

- **& (AND):** Both bits must be 1
- **| (OR):** At least one bit is 1
- **^ (XOR):** Bits must be different
- **~ (NOT):** Inverts all bits
- **<< (Left shift):** Multiply by 2^n
- **>> (Right shift):** Divide by 2^n
- **Use cases:** Flags, optimization, cryptography, graphics
- **Priority:** Use for low-level operations, not everyday code
