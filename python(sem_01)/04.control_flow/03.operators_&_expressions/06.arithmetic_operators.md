# Arithmetic Operators in Python

## Basic Arithmetic Operators

### 1. Addition (+)
```python
a = 10
b = 3
result = a + b      # 13

# String concatenation
name1 = "Hello"
name2 = "World"
greeting = name1 + " " + name2  # "Hello World"

# List concatenation
list1 = [1, 2]
list2 = [3, 4]
combined = list1 + list2        # [1, 2, 3, 4]
```

### 2. Subtraction (-)
```python
a = 10
b = 3
result = a - b      # 7

# Negative numbers
x = 5
y = -x              # -5
```

### 3. Multiplication (*)
```python
a = 10
b = 3
result = a * b      # 30

# String repetition
text = "ab" * 3     # "ababab"

# List repetition
lst = [1, 2] * 3    # [1, 2, 1, 2, 1, 2]
```

### 4. Division (/)
```python
a = 10
b = 3
result = a / b      # 3.333... (float result)

# Division always returns float in Python 3
result = 10 / 2     # 5.0 (not 5)
```

### 5. Floor Division (//)
```python
a = 10
b = 3
result = a // b     # 3 (integer result)

# Rounds towards negative infinity
print(10 // 3)      # 3
print(-10 // 3)     # -4 (not -3)
```

### 6. Modulo (%)
```python
a = 10
b = 3
remainder = a % b   # 1

# Common uses
print(10 % 2)       # 0 (10 is even)
print(11 % 2)       # 1 (11 is odd)

# Negative modulo
print(-10 % 3)      # 2 (in Python: (a % b) = a - b * (a // b))
```

### 7. Exponentiation (**)
```python
a = 2
b = 3
result = a ** b     # 8 (2^3)

# Fractional exponents
x = 16
root = x ** (1/2)   # 4.0 (square root)
cube_root = x ** (1/3)  # 2.519...

# Negative exponents
y = 2 ** -1         # 0.5
```

---

## Operator Precedence

Order of evaluation (highest to lowest):
1. `**` (Exponentiation)
2. `*`, `/`, `//`, `%` (Multiplication, Division)
3. `+`, `-` (Addition, Subtraction)

### Examples
```python
# Without parentheses
result = 2 + 3 * 4          # 14 (not 20)
result = 10 - 2 + 3         # 11 (left to right)

# With parentheses (changes order)
result = (2 + 3) * 4        # 20
result = 2 ** 3 ** 2        # 512 (right to left: 2^9)
```

## Compound Assignment Operators

```python
x = 10

x += 5              # x = x + 5 = 15
x -= 3              # x = x - 3 = 12
x *= 2              # x = x * 2 = 24
x /= 4              # x = x / 4 = 6.0
x //= 2             # x = x // 2 = 3.0
x %= 2              # x = x % 2 = 1.0
x **= 2             # x = x ** 2 = 1.0
```

## Type Coercion in Arithmetic

```python
# int + int → int
result = 10 + 5     # 15

# int + float → float
result = 10 + 5.0   # 15.0

# float + float → float
result = 10.5 + 5.5 # 16.0

# With different types
a = 10              # int
b = 3.0             # float
print(a + b)        # 13.0 (float)
```

## Practical Examples

### Example 1: Simple Calculator
```python
num1 = 10
num2 = 3

print(f"{num1} + {num2} = {num1 + num2}")
print(f"{num1} - {num2} = {num1 - num2}")
print(f"{num1} * {num2} = {num1 * num2}")
print(f"{num1} / {num2} = {num1 / num2}")
print(f"{num1} // {num2} = {num1 // num2}")
print(f"{num1} % {num2} = {num1 % num2}")
print(f"{num1} ** {num2} = {num1 ** num2}")
```

### Example 2: Check Even/Odd
```python
num = 15
if num % 2 == 0:
    print("Even")
else:
    print("Odd")
```

### Example 3: Calculate Average
```python
marks = [85, 90, 78, 92, 88]
total = sum(marks)
average = total / len(marks)
print(f"Average: {average}")
```

## Common Mistakes

### Division Returns Float
```python
# Common mistake
result = 10 / 2
print(result == 5)  # False! (result is 5.0)

# Solution
result = 10 // 2    # Use floor division for int result
print(result == 5)  # True
```

### Operator Precedence
```python
# Without knowing precedence
result = 2 + 3 * 4
# Expected: (2 + 3) * 4 = 20
# Actual: 2 + (3 * 4) = 14

# Always use parentheses for clarity
result = (2 + 3) * 4  # 20
```

### Negative Modulo
```python
# Python: -10 % 3 = 2 (not -1)
# This is different from some other languages
print(-10 % 3)      # 2
print(10 % -3)      # -2
```

## Summary

- **Addition (+):** Add numbers or concatenate strings/lists
- **Subtraction (-):** Subtract numbers
- **Multiplication (*):** Multiply numbers or repeat sequences
- **Division (/):** Always returns float
- **Floor Division (//):** Integer division
- **Modulo (%):** Remainder after division
- **Exponentiation (**):** Power operation
- **Precedence:** ** > */÷ > +/- (Left to right for same precedence)
- **Compound operators:** +=, -=, *=, /=, //=, %=, **=
