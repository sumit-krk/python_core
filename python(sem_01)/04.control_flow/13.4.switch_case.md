# switch-case and match Statement in Python

## Python 3.10+ match Statement (New)

### Syntax
```python
match value:
    case pattern1:
        # Code for pattern1
    case pattern2:
        # Code for pattern2
    case _:
        # Default case (wildcard)
```

### Simple Example
```python
day = 3
match day:
    case 1:
        print("Monday")
    case 2:
        print("Tuesday")
    case 3:
        print("Wednesday")
    case 4:
        print("Thursday")
    case 5:
        print("Friday")
    case 6:
        print("Saturday")
    case 7:
        print("Sunday")
    case _:
        print("Invalid day")
```

## match Examples

### Example 1: Fruit Price
```python
fruit = "apple"
match fruit:
    case "apple":
        price = 50
    case "banana":
        price = 30
    case "orange":
        price = 60
    case _:
        price = 0

print(f"Price: {price}")
```

### Example 2: Simple Operation
```python
operation = "add"
x, y = 10, 5

match operation:
    case "add":
        result = x + y
    case "subtract":
        result = x - y
    case "multiply":
        result = x * y
    case "divide":
        result = x / y if y != 0 else 0
    case _:
        result = None

print(result)
```

## Alternative for Python < 3.10: Dictionary Method

### Using Dictionary (Like switch-case)
```python
def get_day_name(day):
    days = {
        1: "Monday",
        2: "Tuesday",
        3: "Wednesday",
        4: "Thursday",
        5: "Friday",
        6: "Saturday",
        7: "Sunday"
    }
    return days.get(day, "Invalid day")

print(get_day_name(3))  # Wednesday
```

### With Functions
```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

operations = {
    "add": add,
    "subtract": subtract,
    "multiply": multiply
}

operation = "add"
result = operations[operation](10, 5)
print(result)  # 15
```

## if-elif vs match

### Using if-elif-else (All Python versions)
```python
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(grade)
```

### Using match (Python 3.10+)
```python
grade_point = 85
match grade_point:
    case grade_point if grade_point >= 90:
        grade = "A"
    case grade_point if grade_point >= 80:
        grade = "B"
    case grade_point if grade_point >= 70:
        grade = "C"
    case grade_point if grade_point >= 60:
        grade = "D"
    case _:
        grade = "F"

print(grade)
```

## Practical Applications

### Example 1: Status Code
```python
code = 404
match code:
    case 200:
        message = "OK"
    case 404:
        message = "Not Found"
    case 500:
        message = "Server Error"
    case _:
        message = "Unknown"

print(message)
```

### Example 2: Command Parser
```python
command = "start"
match command:
    case "start":
        print("Starting application...")
    case "stop":
        print("Stopping application...")
    case "restart":
        print("Restarting application...")
    case "status":
        print("Checking status...")
    case _:
        print("Unknown command")
```

### Example 3: File Type Handler
```python
filename = "document.pdf"
ext = filename.split(".")[-1]

match ext:
    case "pdf":
        handler = "PDF Reader"
    case "txt":
        handler = "Text Editor"
    case "jpg" | "png" | "gif":
        handler = "Image Viewer"
    case "mp3":
        handler = "Music Player"
    case _:
        handler = "Default Application"

print(f"Handler: {handler}")
```

## match with Multiple Values

```python
user_role = "admin"
action = "delete"

match (user_role, action):
    case ("admin", "delete"):
        print("Performing delete...")
    case ("admin", "read"):
        print("Reading...")
    case ("user", "read"):
        print("Reading...")
    case ("user", "delete"):
        print("Access denied")
    case _:
        print("Unknown role or action")
```

## When to Use match vs if-elif

### Use match for:
- Clean value comparisons
- Many distinct cases
- Simple pattern matching

### Use if-elif for:
- Complex conditions
- Range checks
- Combining multiple conditions
- Python < 3.10 (older versions)

---

## Common Patterns

### Default Case (Wildcard)
```python
match value:
    case 1:
        print("One")
    case 2:
        print("Two")
    case _:  # Matches anything
        print("Other")
```

### Pattern with Condition
```python
age = 25
match age:
    case age if age < 18:
        print("Minor")
    case age if age < 65:
        print("Adult")
    case _:
        print("Senior")
```

---

## Backward Compatibility

For Python versions before 3.10, use if-elif:

```python
# Python < 3.10
day = 3
if day == 1:
    print("Monday")
elif day == 2:
    print("Tuesday")
elif day == 3:
    print("Wednesday")
else:
    print("Other")
```

---

## Summary

- **match statement:** New in Python 3.10+ for pattern matching
- **Dictionary method:** Alternative for switch-like behavior
- **if-elif-else:** Traditional and works on all Python versions
- **Choice:** Use based on Python version and code clarity
- **Performance:** All approaches similar, choose for readability
