# if-else Statement in Python

## Basic if-else Structure

### Syntax
```python
if condition:
    # Code if condition is True
    statement1
else:
    # Code if condition is False
    statement2
```

### Simple Example
```python
age = 15
if age >= 18:
    print("You are an adult")
else:
    print("You are a minor")
```

---

## if-else Examples

### Example 1: Number Check
```python
num = 7
if num % 2 == 0:
    print("Even number")
else:
    print("Odd number")
```

### Example 2: Grade Assignment
```python
score = 75
if score >= 50:
    print("Pass")
else:
    print("Fail")
```

### Example 3: Login Validation
```python
username = input("Enter username: ")
if username == "admin":
    print("Welcome, Admin!")
else:
    print("Access denied")
```

---

## Nested if-else

```python
age = 25
income = 30000

if age >= 18:
    if income > 20000:
        print("Eligible for loan")
    else:
        print("Income too low")
else:
    print("Too young for loan")
```

## Ternary Operator (Conditional Expression)

### Syntax
```python
value_if_true if condition else value_if_false
```

### Examples
```python
age = 20
status = "Adult" if age >= 18 else "Minor"
print(status)       # Adult

x = 5
y = 10
max_val = x if x > y else y
print(max_val)      # 10

# One-liner
print("Even") if 10 % 2 == 0 else print("Odd")
```

## Common Patterns

### Example 1: Validation
```python
password = input("Enter password: ")
if len(password) >= 8:
    print("Strong password")
else:
    print("Password too short")
```

### Example 2: Range Check
```python
temp = 25
if temp < 0:
    print("Below freezing")
else:
    print("Above freezing")
```

### Example 3: String Validation
```python
email = input("Enter email: ")
if "@" in email:
    print("Valid format")
else:
    print("Invalid format")
```

---

## if-else with Ternary Chaining

```python
# Multiple ternary (gets complex, use if-elif-else instead)
score = 75
grade = "A" if score >= 90 else "B" if score >= 80 else "C" if score >= 70 else "D"
print(grade)        # C

# Better approach
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "D"
```

## Practical Applications

### Example 1: Age Group
```python
age = 30
if age < 18:
    category = "Minor"
else:
    category = "Adult"
print(f"You are: {category}")
```

### Example 2: Item Availability
```python
stock = 5
if stock > 0:
    print("Item available")
else:
    print("Out of stock")
```

### Example 3: Pass/Fail
```python
marks = 45
if marks >= 40:
    print("Pass")
else:
    print("Fail")
```

---

## Summary

- **if-else:** Two-way branching
- **Ternary operator:** Compact conditional expression
- **Nesting:** Multiple levels of conditions
- **Use cases:** Different actions for true/false conditions
- **Readability:** Use explicit if-else over complex ternary
