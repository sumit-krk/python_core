# elif Ladder (else-if Chain) in Python

## Basic elif Structure

### Syntax
```python
if condition1:
    # Code if condition1 is True
    statement1
elif condition2:
    # Code if condition2 is True
    statement2
elif condition3:
    # Code if condition3 is True
    statement3
else:
    # Code if all conditions are False
    statement4
```

### Simple Example
```python
score = 85
if score >= 90:
    print("Grade A")
elif score >= 80:
    print("Grade B")
elif score >= 70:
    print("Grade C")
elif score >= 60:
    print("Grade D")
else:
    print("Grade F")
```

---

## Key Points about elif

1. **Multiple conditions:** Check many different cases
2. **First match wins:** Executes only the matching block
3. **Optional else:** Not always needed
4. **Cleaner than nested if:** More readable

```python

attendance = 80

    result = "Excellent"
```

## Order Matters

### Important: elif order affects result
```python
score = 85

# Order 1
if score >= 60:
    print("Passed")  # This executes
elif score >= 80:
    print("Very Good")  # Won't execute

# Order 2
if score >= 80:
    print("Very Good")  # This executes
elif score >= 60:
    print("Passed")  # Won't execute
```

**Always arrange elif conditions from most specific to least specific.**

## elif without else

```python

    print("Positive")
```

## Common Mistakes

### Multiple if instead of elif
```python
# Wrong - checks all conditions
score = 85
if score >= 90:
    print("A")
if score >= 80:      # Also prints "B"!
    print("B")
if score >= 70:      # Also prints "C"!
    print("C")

# Correct - only matching block
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
```

### Unreachable Code
```python
# Wrong - second condition never reached
if score >= 70:
    print("Passed")
elif score >= 90:       # Never executes (covered by first if)
    print("Excellent")

# Correct
if score >= 90:
    print("Excellent")
elif score >= 70:
    print("Passed")
```

## Comparison: if vs if-elif-else

### Multiple if (all checked)
```python
if x > 5:
    print("Greater than 5")
if x > 10:
    print("Greater than 10")
if x > 15:
    print("Greater than 15")
# All matching conditions execute
```

### if-elif-else (only first match)
```python
if x > 15:
    print("Greater than 15")
elif x > 10:
    print("Greater than 10")
elif x > 5:
    print("Greater than 5")
# Only one block executes
```

---

## Summary

- **elif:** Multiple conditions checked sequentially
- **First match:** Only matching block executes
- **Order matters:** Check most specific first
- **More readable:** Than nested if statements
- **Efficiency:** Stops checking after first match
