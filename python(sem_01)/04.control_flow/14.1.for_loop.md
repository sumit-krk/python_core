# for Loop in Python

## Basic for Loop

### Syntax
```python
for variable in sequence:
    # Code to execute
    statement1
    statement2
```

### Simple Examples
```python
# Loop through list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# Loop through string
for char in "Python":
    print(char)

# Loop through range
for i in range(5):
    print(i)  # 0, 1, 2, 3, 4
```

---

## range() Function

### Syntax
```python
range(stop)              # 0 to stop-1
range(start, stop)       # start to stop-1
range(start, stop, step) # start to stop-1 with step
```

### Examples
```python
# 0 to 4
for i in range(5):
    print(i)

# 1 to 5
for i in range(1, 6):
    print(i)

# 0, 2, 4
for i in range(0, 5, 2):
    print(i)

# 10 down to 1
for i in range(10, 0, -1):
    print(i)

# Negative step (reverse)
for i in range(5, 0, -1):
    print(i)
```

## Iterating with Index

### Using enumerate()
```python
fruits = ["apple", "banana", "cherry"]
for index, fruit in enumerate(fruits):
    print(f"{index}: {fruit}")

# Output:
# 0: apple
# 1: banana
# 2: cherry

# Starting index at 1
for index, fruit in enumerate(fruits, 1):
    print(f"{index}: {fruit}")
```

## Nested for Loops

```python
# Multiplication table
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i}*{j}={i*j}", end=" ")
    print()

# Output:
# 1*1=1 1*2=2 1*3=3
# 2*1=2 2*2=4 2*3=6
# 3*1=3 3*2=6 3*3=9
```

## for Loop Examples

### Example 1: Sum Numbers
```python
numbers = [1, 2, 3, 4, 5]
total = 0
for num in numbers:
    total += num
print(f"Sum: {total}")  # 15
```

### Example 2: Print Pattern
```python
for i in range(1, 4):
    for j in range(1, i+1):
        print("*", end="")
    print()

# Output:
# *
# **
# ***
```

### Example 3: Find Maximum
```python
numbers = [3, 7, 2, 9, 1]
max_num = numbers[0]
for num in numbers:
    if num > max_num:
        max_num = num
print(f"Maximum: {max_num}")  # 9
```

## for-else Loop

Else block executes if loop completes normally (no break):

```python
# Normal completion
for i in range(3):
    print(i)
else:
    print("Loop completed")  # Executes

# With break
for i in range(3):
    if i == 1:
        break
    print(i)
else:
    print("Loop completed")  # Won't execute
```

## Practical Applications

### Example 1: List Processing
```python
items = ["apple", "banana", "orange"]

    print(f"Item: {item}")
```

### Example 2: Range of Numbers
```python
# Print squares from 1 to 5
for i in range(1, 6):
    print(f"{i}^2 = {i**2}")
```

### Example 3: String Iteration
```python
word = "hello"
for char in word:

```

## Loop Control with break and continue

### break Statement
```python
for i in range(10):
    if i == 5:
        break
    print(i)  # 0 1 2 3 4
```

### continue Statement
```python
for i in range(5):
    if i == 2:
        continue
    print(i)  # 0 1 3 4
```

---

## Summary

- **for loop:** Iterate through sequences
- **range():** Generate sequence of numbers
- **enumerate():** Get index and value
- **Nested loops:** Multiple levels of iteration
- **for-else:** Optional else clause after loop
- **break:** Exit loop immediately
- **continue:** Skip to next iteration
