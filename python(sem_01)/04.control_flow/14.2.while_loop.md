# while Loop in Python

## Basic while Loop

### Syntax
```python
while condition:
    # Code to execute while condition is True
    statement1
    statement2
```

### Simple Examples
```python
# Count down
count = 5
while count > 0:
    print(count)
    count -= 1

# Loop until condition met
x = 0
while x < 5:
    print(x)
    x += 1
```

---

## Infinite Loop and break

### Infinite Loop (Must Break Manually)
```python
while True:
    user_input = input("Enter 'quit' to exit: ")
    if user_input == "quit":
        break
    print(f"You entered: {user_input}")
```

### Using break to Exit
```python
count = 0
while True:
    count += 1
    if count > 5:
        break
    print(count)
```

---

## while-else Loop

Else executes if loop completes normally:

```python
# Normal completion
count = 0
while count < 3:
    print(count)
    count += 1
else:
    print("Loop completed")  # Executes

# With break
count = 0
while count < 5:
    if count == 2:
        break
    print(count)
    count += 1
else:
    print("Loop completed")  # Won't execute (broken)
```

## while Loop Examples

### Example 1: User Input Validation
```python
while True:
    age = int(input("Enter age (1-120): "))
    if 1 <= age <= 120:
        print(f"Valid age: {age}")
        break
    else:
        print("Please enter valid age")
```

### Example 2: Menu System
```python
choice = ""
while choice != "exit":
    choice = input("Enter command (start/stop/exit): ")
    if choice == "start":
        print("Starting...")
    elif choice == "stop":
        print("Stopping...")
    elif choice == "exit":
        print("Goodbye!")
```

### Example 3: Sum Until Negative
```python
total = 0
while True:
    num = int(input("Enter number (negative to stop): "))
    if num < 0:
        break
    total += num
print(f"Total: {total}")
```

## Loop Control Statements

### continue Statement
```python
count = 0
while count < 5:
    count += 1
    if count == 3:
        continue
    print(count)  # 1 2 4 5
```

### break Statement
```python
count = 0
while count < 10:
    if count == 5:
        break
    print(count)
    count += 1
```

## Comparing for and while

### for Loop (Known Iterations)
```python
# When you know how many times
for i in range(5):
    print(i)
```

### while Loop (Unknown Iterations)
```python
# When you don't know how many times
while input("Continue? (yes/no): ") == "yes":
    print("Continuing...")
```

## Practical Applications

### Example 1: Countdown Timer
```python
import time
count = 5
while count > 0:
    print(f"Starting in {count}...")
    time.sleep(1)
    count -= 1
print("Go!")
```

### Example 2: Password Verification
```python
correct_password = "secret123"
attempts = 3
while attempts > 0:
    password = input("Enter password: ")
    if password == correct_password:
        print("Access granted")
        break
    attempts -= 1
    print(f"Attempts remaining: {attempts}")
```

### Example 3: Fibonacci Sequence
```python
n = 10
a, b = 0, 1
count = 0
while count < n:
    print(a, end=" ")
    a, b = b, a + b
    count += 1
```

## Common Mistakes

### Infinite Loop
```python
# Forgetting to update condition
count = 0
while count < 5:
    print(count)
    # Forgot: count += 1
    # This will loop forever!
```

### Incorrect Condition
```python
# Wrong
while False:
    print("Never prints")

# Correct
while True:
    if some_condition:
        break
    print("Something")
```

---

## Summary

- **while loop:** Repeat while condition is True
- **Infinite loop:** Use while True with break
- **while-else:** Else executes if loop completes normally
- **break:** Exit loop immediately
- **continue:** Skip to next iteration
- **Use cases:** Unknown number of iterations, user input, event-driven
