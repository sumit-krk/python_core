# Python Programming - Practice Questions

## Module 1: Introduction to Python
1. What are the main advantages of Python?
2. How do you run a Python program?
3. What is the difference between interpreted and compiled languages?
4. Write a program to print "Hello, World!"
5. What are Python identifiers?

## Module 2: Data Types
1. What are primitive data types in Python?
2. Write a program to find the type of a variable.
3. Demonstrate type conversion with examples.
4. What is the difference between int and float?
5. How do you create and manipulate strings?

## Module 3: Operators
1. Write a program to demonstrate all arithmetic operators.
2. What is the difference between == and is?
3. Write a program for operator precedence demonstration.
4. How do logical operators work in Python?
5. Demonstrate membership operators (in, not in).

## Module 4: Control Flow
1. Write a program using if-elif-else statements.
2. Create a program using match-case (Python 3.10+).
3. Write a for loop to print multiplication table.
4. Demonstrate the difference between for and while loops.
5. Write a program using nested loops.

## Module 5: Data Structures
1. How to create, access, and modify lists?
2. What are tuples? How are they different from lists?
3. Write a program for list operations (append, insert, remove).
4. Demonstrate string slicing and manipulation.
5. What are list comprehensions?

## Module 6: Functions
1. Write a function to calculate factorial.
2. Explain the difference between parameters and arguments.
3. Write a recursive function.
4. How do default parameters work?
5. What is function documentation?

## Module 7: Modules & Packages
1. How do you import a module in Python?
2. What is the difference between import and from...import?
3. Write a program using the math module.
4. How do you create your own module?
5. What is the __name__ variable?

## Module 8: Object-Oriented Programming
1. Define a class with attributes and methods.
2. Demonstrate inheritance with an example.
3. What is encapsulation?
4. Explain polymorphism in Python.
5. Write a class with __init__ and __str__ methods.

## Module 9: File Handling
1. Write a program to read a file line by line.
2. How do you write to a file in Python?
3. Demonstrate file handling with context manager (with statement).
4. How do you handle file not found exceptions?
5. Write a program to append content to a file.

## Module 10: Advanced Concepts
1. What are decorators? Write a simple decorator.
2. Demonstrate generators with an example.
3. What are lambda functions?
4. Write a list comprehension program.
5. Explain the difference between map(), filter(), and reduce().

---

**Note:** Practice these questions regularly and try to solve them without looking at the solutions.
