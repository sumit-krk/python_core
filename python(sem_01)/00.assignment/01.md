# Assignment 1: Python Basics & Data Types

## Objective
To understand Python basics, variables, data types, and simple operations.

## Questions

### Part A: Fundamentals
1. Write a Python program to display "Hello, World!"
2. Write a program to take input from user and print it.
3. Create variables of different data types and print their types using type() function.
4. Write a program to swap two numbers without using a third variable.
5. Calculate the area of a circle given radius.

### Part B: Data Types
6. Write a program to demonstrate all arithmetic operations (+, -, *, /, //, %, **).
7. Convert an integer to float and vice versa.
8. Write a program to check if a number is odd or even.
9. Create a string and perform various string operations (concatenation, slicing, etc.).
10. Write a program to find the largest of three numbers.

## Submission Guidelines
- File format: .py (Python script)
- Add comments to explain your code
- Test your program with multiple inputs
- Deadline: As per course schedule
