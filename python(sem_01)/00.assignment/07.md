# Assignment 7: Exception Handling & Advanced Features

## Objective
To understand exception handling, decorators, generators, and lambda functions.

## Questions

### Part A: Exception Handling
1. Write a program to handle different types of exceptions (ZeroDivisionError, ValueError, etc.).
2. Write a program with try-except-finally blocks.
3. Write a program to create custom exceptions.
4. Write a program to demonstrate exception chaining.

### Part B: Advanced Features
5. Write a lambda function to filter even numbers from a list.
6. Write a program using map(), filter(), and reduce() functions.
7. Write a simple decorator function and apply it to another function.
8. Write a program to demonstrate generators using yield.
9. Write a list comprehension program with conditions.
10. Write a program using dictionary comprehension.

## Submission Guidelines
- Include error handling for all user inputs
- Provide example outputs for each program
- Document the purpose of each function/decorator
- Test all edge cases
