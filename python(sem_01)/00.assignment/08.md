# Assignment 8: Comprehensive Project

## Objective
To apply all learned concepts in a comprehensive programming project.

## Project Options

### Option 1: Library Management System
- Create classes for Book, Member, and Library
- Implement functions to add/remove books
- Track book borrowing and return
- Generate reports

### Option 2: Student Grade Management System
- Store student information (name, roll_no, marks)
- Calculate grades and GPA
- Handle file I/O for data persistence
- Generate transcript reports

### Option 3: Personal Finance Tracker
- Record income and expenses
- Categorize transactions
- Generate monthly/yearly reports
- Save data to file
- Search and filter transactions

### Option 4: Simple Quiz Application
- Load questions from a file
- Display questions and options
- Calculate score
- Save quiz results
- Show statistics

## Requirements
- Must use OOP concepts (classes, inheritance, encapsulation)
- Must handle exceptions appropriately
- Must use file I/O for data persistence
- Must include proper documentation
- Must have at least 5 functions/methods
- Must be tested with multiple scenarios
