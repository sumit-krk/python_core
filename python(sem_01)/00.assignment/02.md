# Assignment 2: Control Flow & Loops

## Objective
To practice conditional statements and loops in Python.

## Questions

### Part A: Conditionals
1. Write a program to check if a number is positive, negative, or zero.
2. Write a program to check if a number is prime.
3. Write a program to find the grade based on marks using if-elif-else.
4. Write a program to check if a year is a leap year.

### Part B: Loops
5. Write a program to print multiplication table using loops.
6. Write a program to find the sum of first N natural numbers.
7. Write a program to find factorial of a number using a loop.
8. Print the Fibonacci sequence up to N terms.
9. Write a program to print a pyramid pattern using loops.
10. Write a program to count vowels and consonants in a string.

## Submission Guidelines
- Each program should have clear logic
- Use proper variable names
- Add comments where necessary
- Test with multiple test cases
