# Assignment 5: Modules, Packages & File Handling

## Objective
To work with Python modules and file operations.

## Questions

### Part A: Modules & Imports
1. Write a program to demonstrate import of different modules (math, random, datetime).
2. Create your own module with functions and use it in another program.
3. Write a program to use functions from the math module.
4. Write a program to generate random numbers using the random module.
5. Write a program to work with datetime module.

### Part B: File Handling
6. Write a program to read a file and display its contents.
7. Write a program to write data to a file.
8. Write a program to append content to a file.
9. Write a program to read a file line by line and count lines.
10. Write a program to copy content from one file to another.

## Submission Guidelines
- Include sample files for reading/writing operations
- Use context managers (with statement) for file operations
- Handle exceptions appropriately
- Add comments for clarity
