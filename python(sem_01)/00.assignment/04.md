# Assignment 4: Functions & Recursion

## Objective
To understand function definition, calling, and recursive functions.

## Questions

### Part A: Functions
1. Write a function to calculate the sum of two numbers.
2. Write a function with default parameters to calculate power.
3. Write a function that returns multiple values.
4. Write a function to check if a number is prime.
5. Write a function with *args to accept variable number of arguments.

### Part B: Recursion & Advanced
6. Write a recursive function to calculate factorial.
7. Write a recursive function to find the sum of digits.
8. Write a recursive function to print Fibonacci series.
9. Write a function with **kwargs to handle keyword arguments.
10. Write a function to demonstrate the use of local and global variables.

## Submission Guidelines
- Each function should have proper documentation
- Use meaningful function names
- Test functions with various inputs
- Include test cases in your submission
