# Assignment 3: Lists, Tuples & Strings

## Objective
To work with Python data structures: lists, tuples, and strings.

## Questions

### Part A: Lists
1. Write a program to create a list and perform basic operations (append, insert, remove, pop).
2. Write a program to sort a list without using built-in sort() method.
3. Write a program to find the second largest element in a list.
4. Write a program to remove duplicates from a list.
5. Write a program to merge two lists.

### Part B: Tuples & Strings
6. Write a program to demonstrate tuple operations and unpacking.
7. Write a program to perform string slicing and find a substring.
8. Write a program to count the frequency of each character in a string.
9. Write a program to check if a string is a palindrome.
10. Write a program to reverse a string using different methods.

## Submission Guidelines
- Programs should be well-structured
- Use meaningful variable names
- Include error handling where necessary
- Test with edge cases
