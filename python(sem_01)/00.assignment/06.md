# Assignment 6: Object-Oriented Programming

## Objective
To understand classes, objects, and OOP concepts in Python.

## Questions

1. Create a class "Car" with attributes (brand, model, year) and methods to display details.
2. Create a class "Student" with attributes and methods to calculate GPA.
3. Demonstrate inheritance: Create a base class "Animal" and derived class "Dog".
4. Write a program to demonstrate encapsulation using private attributes.
5. Create a class with __init__, __str__, and __repr__ methods.
6. Write a program to demonstrate method overriding.
7. Create a class with class methods and static methods.
8. Write a program to demonstrate polymorphism.
9. Create multiple classes and demonstrate association/composition.
10. Write a program using inheritance with super() method.

## Submission Guidelines
- Each class should have proper documentation
- Use meaningful class and method names
- Include example usage of each class
- Add test cases for all methods
