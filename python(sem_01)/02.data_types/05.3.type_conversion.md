# Type Conversion (Casting) in Python

## Type Conversion Methods

### 1. int() - Convert to Integer
```python
# From string
x = int("25")         # 25
x = int("10.5")       # ValueError

# From float (truncates decimal)
x = int(25.9)         # 25

# From boolean
x = int(True)         # 1
x = int(False)        # 0

# With base conversion
x = int("1010", 2)    # Convert from binary: 10
x = int("1F", 16)     # Convert from hex: 31
```

### 2. float() - Convert to Float
```python
# From string
x = float("3.14")     # 3.14
x = float("5")        # 5.0

# From integer
x = float(10)         # 10.0

# From boolean
x = float(True)       # 1.0
x = float(False)      # 0.0

# Special values
x = float('inf')      # Infinity
x = float('-inf')     # Negative infinity
x = float('nan')      # Not a Number
```

### 3. str() - Convert to String
```python
# From integer
x = str(42)           # "42"

# From float
x = str(3.14)         # "3.14"

# From boolean
x = str(True)         # "True"

# From list
x = str([1, 2, 3])    # "[1, 2, 3]"

# From None
x = str(None)         # "None"
```

### 4. bool() - Convert to Boolean
```python
# From integer
bool(0)               # False
bool(1)               # True
bool(-5)              # True

# From float
bool(0.0)             # False
bool(3.14)            # True

# From string
bool("")              # False
bool("text")          # True

# From collections
bool([])              # False
bool([1, 2])          # True
bool({})              # False
bool({'a': 1})        # True

# From None
bool(None)            # False
```

## Implicit Type Conversion

Python automatically converts types in certain operations:

```python
# Integer + Float → Float
result = 10 + 3.14    # 13.14 (float)

# Integer/Integer → Float (Python 3)
result = 10 / 3       # 3.333... (float)

# In boolean context
if 5:                 # 5 is implicitly converted to True
    print("Yes")

# String concatenation
result = "Value: " + str(42)  # Need explicit conversion
```

## Explicit Type Conversion

### Numeric Conversions
```python
# int to float
a = 10
b = float(a)          # 10.0

# float to int
c = 3.99
d = int(c)            # 3 (truncates)

# Round before converting
e = round(3.99)       # 4
f = int(round(3.99))  # 4
```

### String Conversions
```python
# int/float to string
num_str = str(42)     # "42"
float_str = str(3.14) # "3.14"

# string to int/float
num_int = int("42")   # 42
num_float = float("3.14")  # 3.14

# Number base conversion
hex_str = hex(255)    # "0xff"
oct_str = oct(64)     # "0o100"
bin_str = bin(10)     # "0b1010"

# Reverse conversion
num = int("ff", 16)   # 255
num = int("1010", 2)  # 10
```

## Type Conversion Examples

### Example 1: User Input Processing
```python
# Get input (always string)
age_input = input("Enter age: ")

# Convert to appropriate type
age = int(age_input)

# Use converted value
if age >= 18:
    print("Adult")
else:
    print("Minor")
```

### Example 2: Mixed Operations
```python
num1 = 10        # int
num2 = 3.5       # float

# Adding int and float
result = num1 + num2  # 13.5 (float)

# String representation
output = str(num1) + " + " + str(num2) + " = " + str(result)
print(output)
```

### Example 3: Data Validation
```python
user_input = input("Enter a number: ")

try:
    number = int(user_input)
    print(f"Valid number: {number}")
except ValueError:
    print("Invalid input")
```

## Common Conversion Errors

### ValueError
```python
# String to int fails if not a valid number
int("abc")              # ValueError
int("3.14")             # ValueError

# Solution: Use float first then int
int(float("3.14"))      # 3
```

### TypeError
```python
# Cannot convert list to int directly
int([1, 2, 3])          # TypeError

# Must convert each element
[int(x) for x in ["1", "2", "3"]]  # [1, 2, 3]
```

## Conversion Table

| From | To int | To float | To str | To bool |
|------|--------|----------|--------|---------|
| int | x | int(x) | str(x) | bool(x) |
| float | int(x) | x | str(x) | bool(x) |
| str | int(x)* | float(x)* | x | bool(x)* |
| bool | int(x) | float(x) | str(x) | x |
| list | - | - | str(x) | bool(x)* |
| None | - | - | str(x) | False |

*Only for valid formats

## Best Practices

1. **Always validate input** before conversion
2. **Use try-except** for risky conversions
3. **Be explicit** with type conversions
4. **Use meaningful variable names** to indicate type
5. **Document expected types** in comments/docstrings

---

## Summary

- **Explicit conversion:** Use int(), float(), str(), bool()
- **Implicit conversion:** Python handles automatically in some cases
- **Error handling:** Use try-except for unsafe conversions
- **Type checking:** Verify types before operations
