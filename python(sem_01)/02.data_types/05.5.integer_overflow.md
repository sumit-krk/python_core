# Integer Overflow & Underflow

## Integer Overflow in Python 3

Unlike many other languages, Python 3 does **NOT** have integer overflow. Integers have unlimited precision.

```python
# Very large numbers work fine
big_num = 10**100
print(big_num)  # Works perfectly

# Even larger
huge_num = 2**1000
print(huge_num)  # Works

# Python automatically allocates memory as needed
```

---

## Why No Overflow?

### Dynamic Memory Allocation
- Python integers grow dynamically
- Memory allocated as needed
- Size increases with number magnitude

### Comparison with Other Languages
```
C/C++:  int (32-bit) → Range: -2^31 to 2^31-1
        Overflow after exceeding range
        
Java:   int (32-bit) → Range: -2^31 to 2^31-1
        Overflow causes wraparound
        
Python 3: int → Unlimited precision
        No overflow possible
```

## Float Overflow & Underflow

### Floats Have Limits
```python
import sys

print(sys.float_info.max)         # 1.7976931348623157e+308
print(sys.float_info.min)         # 2.2250738585072014e-308

# Exceeding max causes overflow to infinity
large_float = 10.0 ** 308
print(large_float)                # 1e+308

# Exceeding max beyond limit
overflow = 10.0 ** 309
print(overflow)                   # inf (infinity)

# Exceeding min causes underflow
tiny_float = 10.0 ** -323
print(tiny_float)                 # Very small number (may be 0)
```

### Float Overflow Example
```python
x = 1.8e308  # Near max
print(x)     # 1.8e+308

x = 1.8e308 * 10  # Exceeds max
print(x)     # inf (overflow)

# Operations with infinity
print(float('inf') + 1)           # inf
print(float('inf') - float('inf')) # nan (not a number)
print(float('inf') / float('inf')) # nan
```

---

## Underflow Examples

### Float Underflow
```python
# Very small positive number
y = 1e-308
print(y)  # 1e-308

# Exceeding underflow limit
y = 1e-324
print(y)  # 0.0 (underflow to zero)

# Scientific notation
z = 1e-400
print(z)  # 0.0
```

## Special Float Values

### Infinity
```python
import math

pos_inf = float('inf')
neg_inf = float('-inf')

print(pos_inf > 10**100)          # True
print(pos_inf == pos_inf)         # True
print(pos_inf > neg_inf)          # True

# Using math module
print(math.isinf(float('inf')))   # True
```

### NaN (Not a Number)
```python
import math

nan_val = float('nan')
print(nan_val)                    # nan

# Important: NaN != NaN
print(nan_val == nan_val)         # False
print(nan_val != nan_val)         # True

# Check for NaN
print(math.isnan(nan_val))        # True
```

## Practical Implications

### Integer Arithmetic (Python 3)
```python
# Safe for all calculations
result = 10**100 + 20**50
print(result)  # Works fine

# No wraparound
x = 2**100
y = x * 2
print(y)  # 2^101, no overflow
```

### Float Arithmetic
```python
# Careful with floats
a = 1e308
b = a * 10  # Becomes infinity
print(b)    # inf

# Loss of precision
x = 1.0
for i in range(100):
    x = x + 1e-16
print(x)  # May not equal 100*1e-16 due to precision
```

## Checking for Overflow/Underflow

### For Floats
```python
import math

def check_value(x):
    if math.isinf(x):
        print("Overflow/Underflow detected: Infinity")
    elif math.isnan(x):
        print("Invalid operation: NaN")
    else:
        print(f"Valid value: {x}")

check_value(1e308 * 10)  # inf
check_value(0.1 + 0.2)   # 0.30000000000000004
```

### Using try-except
```python
try:
    x = 10**100
    result = x / 0  # Can't overflow, but zero division
except ZeroDivisionError:
    print("Division by zero!")
```

---

## Best Practices

1. **Use integers for whole numbers** (no overflow in Python 3)
2. **Be cautious with floats** (limited precision and range)
3. **Check for infinity/NaN** when needed
4. **Use Decimal module** for high precision
5. **Document assumptions** about number ranges

### Using Decimal Module
```python
from decimal import Decimal, getcontext

# Set precision
getcontext().prec = 50

a = Decimal('0.1')
b = Decimal('0.2')
result = a + b
print(result)  # 0.3 (exact)
```

---

## Summary

- **Python 3 integers:** Unlimited precision, no overflow
- **Python 3 floats:** Limited range, precision, can overflow/underflow
- **Special values:** inf, -inf, nan
- **Best practice:** Use integers when possible, be careful with floats
- **High precision:** Use Decimal module when needed
