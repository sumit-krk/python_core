# Type Casting in Python

## Explicit Type Casting

### Converting Between Data Types

```python
# int to float
x = int(5)
y = float(x)           # 5.0

# float to int
x = float(3.9)
y = int(x)             # 3 (truncates decimal)

# int/float to string
x = 42
y = str(x)             # "42"

# string to int/float
x = "100"
y = int(x)             # 100

# boolean conversions
x = int(True)          # 1
y = int(False)         # 0
z = float(True)        # 1.0
```

## Conversion Reference

### int() Conversion
```python
int(3.14)              # 3
int("42")              # 42
int("1010", 2)         # 10 (binary)
int("FF", 16)          # 255 (hexadecimal)
int(True)              # 1
```

### float() Conversion
```python
float(10)              # 10.0
float("3.14")          # 3.14
float("inf")           # infinity
float(True)            # 1.0
```

### str() Conversion
```python
str(42)                # "42"
str(3.14)              # "3.14"
str(True)              # "True"
str([1,2,3])           # "[1, 2, 3]"
```

### list() Conversion
```python
list("ABC")            # ['A', 'B', 'C']
list((1,2,3))          # [1, 2, 3]
list({1,2,3})          # [1, 2, 3]
list(range(3))         # [0, 1, 2]
```

### tuple() Conversion
```python
tuple([1,2,3])         # (1, 2, 3)
tuple("ABC")           # ('A', 'B', 'C')
tuple({1,2,3})         # (1, 2, 3)
```

### set() Conversion
```python
set([1,2,2,3])         # {1, 2, 3} - removes duplicates
set("ABBA")            # {'A', 'B'}
set((1,2,3))           # {1, 2, 3}
```

### dict() Conversion
```python
dict([('a', 1), ('b', 2)])  # {'a': 1, 'b': 2}
```

## Casting Examples

### Example 1: Arithmetic Operations
```python
num1 = 10           # int
num2 = 3.5          # float

# Result is float
result = num1 + num2    # 13.5

# Cast to int if needed
result_int = int(result) # 13
```

### Example 2: String Operations
```python
name = "John"
age = 25

# Convert int to string for concatenation
message = name + " is " + str(age) + " years old"
print(message)
```

### Example 3: User Input Processing
```python
# Input is always string
user_input = input("Enter a number: ")

# Convert to appropriate type
try:
    number = int(user_input)
    squared = number ** 2
    print(f"Square: {squared}")
except ValueError:
    print("Invalid number")
```

## Casting with Collections

### List Casting
```python
# Convert tuple to list
t = (1, 2, 3)
lst = list(t)        # [1, 2, 3] - mutable

# Convert string to list
s = "Hello"
chars = list(s)      # ['H', 'e', 'l', 'l', 'o']

# Convert set to list
st = {3, 1, 2}
lst = list(st)       # [1, 2, 3] - order may vary
```

### Tuple Casting
```python
# Convert list to tuple
lst = [1, 2, 3]
t = tuple(lst)       # (1, 2, 3) - immutable

# Convert string to tuple
s = "ABC"
t = tuple(s)         # ('A', 'B', 'C')
```

## Common Casting Errors

### ValueError
```python
# String doesn't contain valid number
int("abc")           # ValueError
float("xyz")         # ValueError

# Solution
try:
    x = int("abc")
except ValueError:
    print("Not a valid integer")
```

### TypeError
```python
# Cannot convert list to int directly
int([1,2,3])         # TypeError

# Solution: convert elements
[int(x) for x in lst]
```

### Loss of Precision
```python
# Float to int truncates
int(3.99)            # 3 (loses 0.99)

# Solution: use round first
int(round(3.99))     # 4
```

## Casting Chains

```python
# Multiple conversions
x = "123"
y = int(x)           # "123" → 123
z = float(y)         # 123 → 123.0
w = str(z)           # 123.0 → "123.0"

# Or in one line
result = str(float(int("123")))  # "123.0"
```

## ord() and chr() - Character Casting

```python
# Character to ASCII/Unicode
print(ord('A'))      # 65
print(ord('a'))      # 97
print(ord('0'))      # 48

# ASCII/Unicode to Character
print(chr(65))       # 'A'
print(chr(97))       # 'a'
print(chr(48))       # '0'

# Unicode example
print(chr(8364))     # '€' (Euro sign)
print(ord('€'))      # 8364
```

## Best Practices

1. **Always validate input** before casting
2. **Use try-except** for risky conversions
3. **Be aware of precision loss** when converting float to int
4. **Use meaningful variable names** to indicate type
5. **Document expected types** in your code

---

## Summary

- Use conversion functions: int(), float(), str(), list(), tuple(), set()
- Handle errors with try-except
- Be aware of precision loss
- Validate input before conversion
- Use ord() and chr() for character conversion
