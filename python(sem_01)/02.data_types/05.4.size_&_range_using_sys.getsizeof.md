# Size & Range Using sys.getsizeof()

## Memory Size in Python

### sys.getsizeof() Function
```python
import sys

# Check size of objects
size_int = sys.getsizeof(10)
size_float = sys.getsizeof(3.14)
size_str = sys.getsizeof("Hello")

print(f"Size of int: {size_int} bytes")
print(f"Size of float: {size_float} bytes")
print(f"Size of str: {size_str} bytes")
```

---

## Typical Sizes (Python 3.x on 64-bit system)

### Basic Types
```python
import sys

print(sys.getsizeof(0))           # 28 bytes (int)
print(sys.getsizeof(10))          # 28 bytes (int)
print(sys.getsizeof(1000))        # 28 bytes (int)
print(sys.getsizeof(3.14))        # 24 bytes (float)
print(sys.getsizeof(True))        # 28 bytes (bool)
print(sys.getsizeof(""))          # 49 bytes (str - empty)
print(sys.getsizeof("Hello"))     # 54 bytes (str)
```

### Collection Types
```python
print(sys.getsizeof([]))          # 56 bytes (list - empty)
print(sys.getsizeof([1,2,3]))     # 88 bytes (list with 3 items)
print(sys.getsizeof(()))          # 40 bytes (tuple - empty)
print(sys.getsizeof((1,2,3)))     # 72 bytes (tuple with 3 items)
```

## Integer Range

### Python 3 - Arbitrary Precision
```python
# Python 3 has unlimited integer range
big_num = 10**100
print(big_num)        # Can handle very large numbers

print(sys.getsizeof(10**10))      # 32 bytes
print(sys.getsizeof(10**100))     # 48 bytes
print(sys.getsizeof(10**1000))    # 176 bytes
```

### Why Size Changes
- Larger numbers require more bytes
- Python allocates memory dynamically
- Object overhead is included in size

## Float Range and Precision

### Float Limitations
```python
import sys

# Min and max float values
print(sys.float_info.max)         # 1.7976931348623157e+308
print(sys.float_info.min)         # 2.2250738585072014e-308

# Precision
print(sys.float_info.dig)         # 15 (significant digits)
print(sys.float_info.epsilon)     # 2.220446049250313e-16
```

### Float Precision Issues
```python
# Floating-point precision problems
print(0.1 + 0.2)          # 0.30000000000000004
print(0.1 + 0.2 == 0.3)   # False

# Solution: Use decimal module
from decimal import Decimal
a = Decimal('0.1')
b = Decimal('0.2')
print(a + b)              # 0.3
print(a + b == Decimal('0.3'))  # True
```

## String Size

### String Length vs Size
```python
import sys

s = "Hello"
print(len(s))                     # 5 (characters)
print(sys.getsizeof(s))           # 54 (bytes with overhead)

# Larger string
s2 = "Hello World" * 100
print(len(s2))                    # 1200
print(sys.getsizeof(s2))          # 1249
```

## Memory Comparison Examples

### Example 1: Integer vs Float
```python
import sys

int_val = 42
float_val = 42.0

print(f"Integer: {sys.getsizeof(int_val)} bytes")
print(f"Float: {sys.getsizeof(float_val)} bytes")
print(f"Difference: {sys.getsizeof(float_val) - sys.getsizeof(int_val)} bytes")
```

### Example 2: Container Sizes
```python
import sys

lst = [1, 2, 3, 4, 5]
tpl = (1, 2, 3, 4, 5)

print(f"List size: {sys.getsizeof(lst)} bytes")
print(f"Tuple size: {sys.getsizeof(tpl)} bytes")
print(f"List is {sys.getsizeof(lst) - sys.getsizeof(tpl)} bytes larger")
```

### Example 3: String Memory
```python
import sys

strings = ["a", "ab", "abc", "abcd", "abcde"]
for s in strings:
    print(f"String '{s}': {sys.getsizeof(s)} bytes")
```

## Python 2 vs Python 3 Integer Types

### Python 2
- `int`: 32-bit or 64-bit (platform dependent)
- `long`: Unlimited precision
- Range limits on int type

### Python 3
- Only `int` type
- Automatic unlimited precision
- No separate long type

## Practical Considerations

### Memory Optimization
```python
# Use tuple instead of list if not modifying
data = (1, 2, 3)        # More memory efficient

# Use generator for large sequences
def generate():
    for i in range(1000000):
        yield i

# Use set for membership tests (faster than list)
items = {1, 2, 3, 4, 5}  # O(1) lookup
```

### When Size Matters
- Processing large datasets
- Embedded systems with limited memory
- Real-time applications
- Long-running servers

## Summary

- **sys.getsizeof():** Check object memory size
- **Python 3 integers:** Unlimited precision
- **Floats:** ~15 significant digits, limited range
- **Strings:** Size depends on content length
- **Collections:** Overhead + element sizes
- **Memory awareness:** Important for optimization
