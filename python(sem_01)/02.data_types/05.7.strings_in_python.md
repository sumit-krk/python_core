# Strings in Python

## String Basics

### String Declaration
```python
# Using double quotes
s1 = "Hello, World!"

# Using single quotes
s2 = 'Hello, World!'

# Using triple quotes (multi-line)
s3 = """This is a
multi-line string"""

# Raw string (escape characters ignored)
s4 = r"C:\Users\Documents"
```

---

## String Operations

### Concatenation
```python
s1 = "Hello"
s2 = "World"
result = s1 + " " + s2    # "Hello World"

# Repetition
pattern = "ab" * 3         # "ababab"

# Join
words = ["Hello", "World"]
result = " ".join(words)   # "Hello World"
```

### String Indexing
```python
s = "Python"
print(s[0])               # 'P'
print(s[3])               # 'h'
print(s[-1])              # 'n' (last character)
print(s[-2])              # 'o' (second last)
```

### String Slicing
```python
s = "Python"
print(s[0:3])             # "Pyt"
print(s[2:5])             # "tho"
print(s[:3])              # "Pyt" (from beginning)
print(s[3:])              # "hon" (to end)
print(s[::2])             # "Pto" (every 2nd character)
print(s[::-1])            # "nohtyP" (reverse)
```

## String Methods

### Case Conversion
```python
s = "Hello, World!"
print(s.upper())          # "HELLO, WORLD!"
print(s.lower())          # "hello, world!"
print(s.capitalize())     # "Hello, world!"
print(s.title())          # "Hello, World!"
print(s.swapcase())       # "hELLO, wORLD!"
```

### Searching
```python
s = "Hello, World!"
print(s.find("o"))        # 4 (first occurrence)
print(s.rfind("o"))       # 8 (last occurrence)
print(s.count("l"))       # 3
print(s.startswith("Hell"))    # True
print(s.endswith("!"))    # True
print("World" in s)       # True (membership)
```

### Replacing
```python
s = "Hello, World!"
print(s.replace("World", "Python"))  # "Hello, Python!"
print(s.replace("l", "L", 1))        # "HeLlo, World!"
```

### Splitting and Joining
```python
s = "Hello, World, Python"
words = s.split(",")      # ['Hello', ' World', ' Python']
result = "-".join(words)  # "Hello- World- Python"

s = "one two three"
print(s.split())          # ['one', 'two', 'three']
```

### Trimming
```python
s = "  Hello, World!  "
print(s.strip())          # "Hello, World!"
print(s.lstrip())         # "Hello, World!  "
print(s.rstrip())         # "  Hello, World!"
print(s.strip("!"))       # "  Hello, World  "
```

## String Formatting

### f-Strings (Python 3.6+)
```python
name = "Alice"
age = 30
print(f"Name: {name}, Age: {age}")

# With expressions
x, y = 10, 20
print(f"Sum: {x + y}")

# With formatting
price = 19.99
print(f"Price: ${price:.2f}")
```

### format() Method
```python
print("Name: {}, Age: {}".format("Bob", 25))
print("{1} is {0}".format("Python", "I"))
print("{name} is {age}".format(name="Charlie", age=35))
```

### % Formatting (Old Style)
```python
print("Name: %s, Age: %d" % ("David", 28))
print("Float: %.2f" % 3.14159)
```

## String Properties

### Length
```python
s = "Python"
print(len(s))             # 6
```

### Membership Testing
```python
print("P" in "Python")    # True
print("x" in "Python")    # False
print("Py" in "Python")   # True
```

### Immutability
```python
s = "Hello"
# s[0] = "J"             # TypeError - strings are immutable
# To modify, create new string
s = "J" + s[1:]          # "Jello"
```

## Escape Sequences

```python
print("Hello\nWorld")     # Newline
print("Tab\there")       # Tab
print("Path: C:\\Users")  # Backslash
print('He said "Hi"')     # Quotes
print("It\'s")           # Escaped quote
print("\u0041")           # Unicode (A)
```

## String Validation

```python
s = "Hello123"
print(s.isalpha())        # False (has digits)
print(s.isdigit())        # False (has letters)
print(s.isalnum())        # True (letters and digits)

s2 = "Hello"
print(s2.isalpha())       # True

s3 = "123"
print(s3.isdigit())       # True

s4 = "   "
print(s4.isspace())       # True

print("Hello".islower())  # False
print("hello".islower())  # True
print("HELLO".isupper())  # True
```

## Practical Examples

### Example 1: Email Validation
```python
email = "user@example.com"
if "@" in email and "." in email:
    print("Valid email format")
else:
    print("Invalid email")
```

### Example 2: String Manipulation
```python
sentence = "the quick brown fox"
words = sentence.split()
capitalized = " ".join([word.capitalize() for word in words])
print(capitalized)  # "The Quick Brown Fox"
```

### Example 3: Password Strength
```python
password = "MyPass123"
print("Has upper:", any(c.isupper() for c in password))
print("Has lower:", any(c.islower() for c in password))
print("Has digit:", any(c.isdigit() for c in password))
print("Length:", len(password))
```
