# Primitive Data Types in Python

## Numeric Types

### 1. Integer (int)
```python
# Integer literals
x = 10
y = -5
z = 0

# Large numbers
large = 123456789012345

# Binary, Octal, Hexadecimal
binary = 0b1010       # 10
octal = 0o12          # 10
hexa = 0xA            # 10

print(type(10))       # <class 'int'>
```

### 2. Float (float)
```python
# Float literals
x = 3.14
y = -2.5
z = 0.0

# Scientific notation
scientific = 1.5e-3   # 0.0015
scientific2 = 2E5     # 200000.0

# Float from division
result = 10 / 3       # 3.333...

print(type(3.14))     # <class 'float'>
```

### 3. Complex (complex)
```python
# Complex numbers
c = 3 + 4j
c = complex(3, 4)     # 3+4j

real_part = c.real    # 3.0
imag_part = c.imag    # 4.0

print(type(3+4j))     # <class 'complex'>
```

---

## Boolean Type (bool)

```python
# Boolean literals
flag1 = True
flag2 = False

# Boolean from comparison
result = 5 > 3        # True
result = 5 < 3        # False

# Type of True/False
print(type(True))     # <class 'bool'>

# Boolean arithmetic (True=1, False=0)
print(True + True)    # 2
print(True + False)   # 1
print(True * 2)       # 2
```

---

## String Type (str)

```python
# String literals
s1 = "Hello"
s2 = 'World'
s3 = """Multi-line
    string"""

# Empty string
empty = ""

# String with escape characters
escaped = "Hello\nWorld"
escaped = "C:\\Users\\Documents"

# Raw string
raw = r"C:\Users\Documents"

print(type("Hello"))  # <class 'str'>
```

### String Operations
```python
# Concatenation
greeting = "Hello" + " " + "World"

# Repetition
pattern = "x" * 5     # "xxxxx"

# Length
length = len("Python")    # 6

# Indexing
first = "Python"[0]       # 'P'
last = "Python"[-1]       # 'n'

# Slicing
substring = "Python"[0:3]  # "Pyt"
```

## None Type

```python
# None represents absence of value
x = None

# Function with no return statement
def func():
    pass

result = func()
print(result)         # None
print(type(None))     # <class 'NoneType'>

# Check for None
if x is None:
    print("x is None")
```

## Type Conversions

### int() - Convert to Integer
```python
int(3.14)             # 3
int("10")             # 10
int(True)             # 1
int(False)            # 0
```

### float() - Convert to Float
```python
float(10)             # 10.0
float("3.14")         # 3.14
float(True)           # 1.0
```

### str() - Convert to String
```python
str(42)               # "42"
str(3.14)             # "3.14"
str(True)             # "True"
```

### bool() - Convert to Boolean
```python
bool(1)               # True
bool(0)               # False
bool("text")          # True
bool("")              # False
bool(None)            # False
```

## Truthy and Falsy Values

### Falsy Values
```python
False, 0, 0.0, "", [], (), {}, None
```

### Truthy Values
```python
True, 1, -1, "text", [1, 2], (1, 2), {'a': 1}
```

### Examples
```python
if 0:
    print("This won't print")  # 0 is falsy

if "Hello":
    print("This will print")   # Non-empty string is truthy

if []:
    print("This won't print")  # Empty list is falsy
```

## Numeric Operations

```python
# Arithmetic
print(10 + 3)         # 13
print(10 - 3)         # 7
print(10 * 3)         # 30
print(10 / 3)         # 3.333...
print(10 // 3)        # 3 (floor division)
print(10 % 3)         # 1 (modulo)
print(2 ** 3)         # 8 (exponentiation)

# Comparisons
print(10 > 3)         # True
print(10 < 3)         # False
print(10 == 10)       # True
print(10 != 3)        # True
```

---

## Key Points

1. **Integers:** Whole numbers, unlimited precision
2. **Floats:** Decimal numbers, approximate values
3. **Complex:** Real and imaginary parts
4. **Boolean:** True or False
5. **Strings:** Text data, sequences of characters
6. **None:** Represents nothing/absence
7. **Immutable:** int, float, bool, str, complex cannot be changed
8. **Type Checking:** Use type() or isinstance()
