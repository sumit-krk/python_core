# Overview of Data Types in Python

## Definition
A data type defines the type of value a variable can hold and the operations that can be performed on it.

---

## Data Type Categories

### 1. **Primitive (Built-in) Data Types**
- int
- float
- bool
- str
- None

### 2. **Collection Data Types**
- list
- tuple
- set
- dict

### 3. **Other Data Types**
- complex
- bytes
- bytearray
- frozenset

## Checking Data Types

### Using type() Function
```python
x = 10
print(type(x))          # <class 'int'>

y = 3.14
print(type(y))          # <class 'float'>

z = "Hello"
print(type(z))          # <class 'str'>

lst = [1, 2, 3]
print(type(lst))        # <class 'list'>
```

### Using isinstance() Function
```python
x = 10
print(isinstance(x, int))       # True
print(isinstance(x, (int, float)))  # True
```

---

## Dynamic Typing

Python allows changing variable type at runtime:

```python
x = 10           # int
print(type(x))   # <class 'int'>

x = "Hello"      # str
print(type(x))   # <class 'str'>

x = [1, 2, 3]    # list
print(type(x))   # <class 'list'>
```

---

## Type Conversion (Casting)

```python
# String to Integer
x = int("10")           # 10

# String to Float
y = float("3.14")       # 3.14

# Integer to String
z = str(10)             # "10"

# String to Boolean
b = bool("False")       # True (non-empty string)

# List to Tuple
lst = [1, 2, 3]
tpl = tuple(lst)        # (1, 2, 3)
```

---

## Data Type Characteristics

| Type | Mutability | Example | Use Case |
|------|-----------|---------|----------|
| int | Immutable | 10, -5 | Counting, indexing |
| float | Immutable | 3.14, -0.5 | Measurements, decimals |
| bool | Immutable | True, False | Conditions, flags |
| str | Immutable | "Hello" | Text data |
| list | Mutable | [1, 2, 3] | Ordered collection |
| tuple | Immutable | (1, 2, 3) | Immutable sequences |
| set | Mutable | {1, 2, 3} | Unique elements |
| dict | Mutable | {'a': 1} | Key-value pairs |

---

## Key Points

1. **Dynamic Typing:** Variables can change types
2. **Type Checking:** Use type() and isinstance()
3. **Type Conversion:** Use int(), float(), str(), etc.
4. **Mutability:** Some types can be modified, others cannot
5. **None Type:** Represents absence of value

---

## Summary

Python has diverse data types to handle different kinds of information. Understanding these types is crucial for writing effective Python programs.
