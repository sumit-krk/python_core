# Python Programming - Sample Paper 1
## Semester 1 Examination

**Duration:** 2 hours
**Total Marks:** 50

### Part A: Multiple Choice Questions (10 marks)
*Each question carries 1 mark*

1. What is the correct syntax to create a function in Python?
   - a) function myFunc(): 
   - b) def myFunc():
   - c) def myFunc(){}
   - d) function myFunc(){}

2. Which of the following is a mutable data type in Python?
   - a) Tuple
   - b) String
   - c) List
   - d) int

3. What does the len() function return for a string "Python"?
   - a) 5
   - b) 6
   - c) 7
   - d) Error

4. Which operator has the highest precedence in Python?
   - a) +
   - b) *
   - c) **
   - d) /

5. What is the output of print(3 ** 2)?
   - a) 6
   - b) 9
   - c) 5
   - d) 8

6. Which keyword is used to exit a loop?
   - a) exit
   - b) break
   - c) stop
   - d) return

7. What does the range(5) function produce?
   - a) 1 to 5
   - b) 0 to 5
   - c) 0 to 4
   - d) 1 to 4

8. How do you create an empty list?
   - a) list()
   - b) []
   - c) Both a and b
   - d) {}

9. What is the output of isinstance(True, int)?
   - a) True
   - b) False
   - c) None
   - d) Error

10. Which of the following is NOT a Python keyword?
    - a) lambda
    - b) yield
    - c) void
    - d) finally

### Part B: Short Answer Questions (20 marks)
*Each question carries 2 marks*

1. Write a program to check if a number is prime.
2. Explain the difference between append() and insert() methods of lists.
3. Write a function that returns the factorial of a number.
4. What is the purpose of the __name__ variable?
5. Explain inheritance with a suitable example.
6. Write a program to reverse a string.
7. What are the differences between local and global variables?
8. Write a program using exception handling.
9. Explain the zip() function with an example.
10. What are decorators in Python?

---

### Part C: Long Answer Questions (20 marks)
*Each question carries 5 marks*

1. Write a program to find the largest element in a list without using the max() function. Explain the logic.

2. Create a class called "Student" with attributes name, roll_no, and marks. Write methods to set and display the details.

3. Write a program that reads from a file, counts the number of lines, words, and characters, and writes the result to another file.

4. Explain the difference between list comprehension and loops. Provide an example of list comprehension and its equivalent using a loop.
