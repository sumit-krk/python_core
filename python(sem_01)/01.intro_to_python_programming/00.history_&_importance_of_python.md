# Python Programming: Introduction, History & Importance

## 1. What Is Programming?

**Programming** is the process of writing step-by-step instructions that tell a computer what to do.

In simple words:

> **Programming = Giving instructions to a computer to perform a task.**

---

## 2. What Is Python?

**Python** is a **high-level, interpreted, strongly typed, and dynamically typed programming language** known for its simple and readable syntax.

Example:

```python
print("Hello World!")
```

Python allows us to perform the same task with much less code than many traditional languages.

### Why Is Python Easy to Learn?

Python's syntax is clean and close to natural language, making it easier to read, write, and understand.

## 5. High-Level Language

A **high-level language** is designed to be easier for humans to read and write while hiding many low-level hardware details.

| High-Level | Low-Level |
|---|---|
| Human-readable | Hardware-oriented |
| Easier to learn | More difficult |
| Hides hardware details | Provides more hardware control |
| Example: Python, Java | Example: Assembly, Machine Code |

> **Python focuses more on programmer productivity than direct hardware control.**

---

## 6. Is Python Strongly Typed?

Yes. Python is generally considered **strongly typed**.

It does not automatically combine incompatible types in many operations.

```python
x = 10
y = "20"

print(x + y)
```

This produces a `TypeError`.

We can explicitly convert the string:

```python
print(x + int(y))
```

Output:

```text
30
```

Python is also **dynamically typed**, meaning the type of a variable is determined at runtime.

```python
x = 10
x = "Hello"
```

The same variable name can refer to objects of different types at different times.

## 8. First Python Program

```python
print("Hello World!")
```

### Understanding It

- `print()` → Built-in Python function
- `"Hello World!"` → String
- `print()` → Displays the value on the screen

Output:

```text
Hello World!
```

### Python vs C

**Python:**

```python
print("Hello World!")
```

**C:**

```c
#include <stdio.h>

int main() {
    printf("Hello World!");
    return 0;
}
```

Python expresses the same simple task with significantly less code.
