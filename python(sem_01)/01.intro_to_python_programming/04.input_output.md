# Input/Output in Python

## Output Operations

### print() Function

#### Basic Syntax
```python
print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)
```

#### Examples

```python
# Simple print
print("Hello, World!")

# Multiple arguments
print("Name:", "John", "Age:", 25)

# Using sep parameter (separator)
print("a", "b", "c", sep="-")          # Output: a-b-c
print("a", "b", "c", sep="")           # Output: abc

# Using end parameter
print("Hello", end=" ")
print("World")                           # Output: Hello World

# Using format strings
name = "Alice"
age = 30
print(f"Name: {name}, Age: {age}")      # f-string (Python 3.6+)
print("Name: {}, Age: {}".format(name, age))  # format method
print("Name: %s, Age: %d" % (name, age))      # % formatting
```

#### Formatting Options

```python
# F-string formatting
price = 19.99
print(f"Price: ${price:.2f}")

# format() method
print("Number: {:.2f}".format(3.14159))
print("{name} is {age} years old".format(name="Bob", age=25))

# % formatting
print("Value: %d" % 42)
print("Float: %.2f" % 3.14159)
```

## Input Operations

### input() Function

#### Basic Syntax
```python
input(prompt='')
```

The `input()` function:
- Displays a prompt
- Reads a line from user input
- Returns the input as a **string**

#### Examples

```python
# Simple input
name = input("Enter your name: ")
print(f"Hello, {name}")

# Input with type conversion
age = int(input("Enter your age: "))
height = float(input("Enter height (in meters): "))

# Multiple inputs
x, y = input("Enter two numbers: ").split()
print(f"x = {x}, y = {y}")
```

---

## Important Notes about input()

1. **Always returns a string**
   ```python
   age = input("Age: ")      # Returns "25" (string)
   print(type(age))          # <class 'str'>
   ```

2. **Type conversion is necessary**
   ```python
   age = int(input("Age: ")) # Convert to integer
   ```

3. **Handling split input**
   ```python
   a, b = input("Enter two numbers: ").split()
   a = int(a)
   b = int(b)
   ```

## Input/Output Examples

### Example 1: Simple Calculator
```python
# Input
num1 = int(input("Enter first number: "))
num2 = int(input("Enter second number: "))

# Processing
sum_result = num1 + num2

# Output
print(f"Sum of {num1} and {num2} is {sum_result}")
```

```python
name = input("Enter name: ")
roll_no = int(input("Enter roll number: "))

print(f"Name: {name}")

```

```python

first = input("First: ")
second = input("Second: ")

# Method 2: Single input with split()
first, second = input("Enter two values: ").split()

# Method 3: List of inputs
values = input("Enter numbers (space-separated): ").split()
numbers = [int(v) for v in values]
```

## Formatted Output

### Using f-strings (Python 3.6+)
```python
name = "Python"
version = 3.9
print(f"Welcome to {name} {version}")

# With formatting
value = 42.123456
print(f"Value: {value:.2f}")  # 42.12
```

### Using format() method
```python
print("Hello, {}!".format("World"))
print("Name: {}, Age: {}".format("John", 25))
print("x = {x}, y = {y}".format(x=10, y=20))
```

### Using % formatting (old style)
```python
print("Number: %d" % 42)
print("String: %s" % "Python")
print("Float: %.2f" % 3.14)
```

## Format Specifiers

```python
# Integer
"{:d}".format(42)              # 42

# Float
"{:.2f}".format(3.14159)       # 3.14

# Exponential
"{:e}".format(1000)            # 1.000000e+03

# Percentage
"{:.1%}".format(0.75)          # 75.0%

# Right-aligned
"{:>10}".format("Python")      # "    Python"

# Left-aligned
"{:<10}".format("Python")      # "Python    "

# Center-aligned
"{:^10}".format("Python")      # "  Python  "

# Zero-padding
"{:05d}".format(42)            # 00042
```

## Common Pitfalls

1. **Forgetting type conversion**
   ```python
   # Wrong
   age = input("Age: ")
   age = age + 1              # Error!
   
   # Correct
   age = int(input("Age: "))
   age = age + 1              # Works
   ```

2. **Mixing input() with split()**
   ```python
   # Wrong
   a, b = int(input("Two numbers: "))  # Error
   
   # Correct
   a, b = map(int, input("Two numbers: ").split())
   ```

3. **Not handling invalid input**
   ```python
   # Better approach
   try:
       age = int(input("Age: "))
   except ValueError:
       print("Please enter a valid number")
   ```

## Summary

- **print():** Display output with formatting options
- **input():** Read user input (always returns string)
- **Type conversion:** Use int(), float(), str() when needed
- **Formatting:** Use f-strings, format(), or % formatting
- **Error handling:** Always validate user input
