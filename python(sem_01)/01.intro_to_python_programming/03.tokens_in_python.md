# Tokens in Python

## Definition
A token is the smallest unit of a program recognized by Python compiler/interpreter.

---

## Types of Tokens

### 1. Keywords
Reserved words with special meaning to Python.

```python
# Control flow keywords
if, else, elif, for, while, break, continue, pass
try, except, finally, raise

# Definition keywords
def, class, return, yield

# Import keywords
import, from, as

# Other keywords
and, or, not, in, is, None, True, False
lambda, global, nonlocal, assert, del
with, except
```

**Total Python 3.x Keywords:** ~35

---

### 2. Identifiers
Names given to variables, functions, classes, etc.

```python
# Valid identifiers
my_variable = 10
_private_var = 20
MyClass = object
userName123 = "John"

# Invalid identifiers
# 123name = 10        # Starts with number
# my-variable = 10    # Contains hyphen
# class = 10          # Reserved keyword
```

**Rules for Identifiers:**
- Start with letter (a-z, A-Z) or underscore (_)
- Followed by letters, digits, or underscores
- Case-sensitive
- Cannot be a keyword
- No spaces or special characters (except _)

---

### 3. Literals
Fixed values in the code.

```python
# Integer literals
10, -5, 0, 100

# Float literals
3.14, -2.5, 0.0

# String literals
"Hello", 'Python', """Multi-line string"""

# Boolean literals
True, False

# Special literal
None
```

---

### 4. Operators
Symbols that perform operations.

```python
# Arithmetic operators
+ , - , * , / , // , % , **

# Comparison operators
== , != , < , > , <= , >=

# Logical operators
and, or, not

# Assignment operators
= , += , -= , *= , /= , //= , %= , **=

# Membership operators
in, not in

# Identity operators
is, is not

# Bitwise operators
& , | , ^ , ~ , << , >>
```

---

### 5. Delimiters
Special characters that structure the code.

```python
# Parentheses
()          # Function calls, expressions

# Brackets
[]          # Lists, indexing

# Braces
{}          # Dictionaries, sets

# Punctuation
:           # Define blocks (if, def, class, etc.)
;           # Separate statements
,           # Separate values
.           # Attribute access
@           # Decorator
->          # Return type annotation
=           # Assignment
```

---

## Tokenization Example

```python
# Source Code
x = 10 + 20

# Tokens Generated
[NAME 'x', OP '=', NUMBER '10', OP '+', NUMBER '20', NEWLINE]
```

## Important Notes

1. **Keywords are case-sensitive:** `If` is not a keyword
2. **Identifiers are case-sensitive:** `Name` and `name` are different
3. **Keywords cannot be used as identifiers**
4. **Use meaningful identifier names** for code readability
5. **Follow naming conventions:** snake_case for variables, UPPERCASE for constants

---

## Quick Reference

```python
# Check if a string is a keyword
import keyword
print(keyword.kwlist)                    # All keywords
print(keyword.iskeyword('for'))          # True
print(keyword.iskeyword('myvar'))        # False
```

## Summary

Python tokens are fundamental building blocks:
- **Keywords:** Control program flow
- **Identifiers:** Name variables and functions
- **Literals:** Represent fixed values
- **Operators:** Perform operations
- **Delimiters:** Structure the code
