# Python Basics: Variables

## 1. What Is a Variable?

A **variable** is a meaningful name that refers to a value in a Python program.

Think of it as a labeled box:

```text
name   ───► "Rahul"
age    ───► 18
marks  ───► 85.5
```

In Python:

```python
name = "Rahul"
age = 18
marks = 85.5
```

### Basic Syntax

```text
variable_name = value
```

Here, `=` is the **assignment operator**.

```python
age = 18
```

Read it as:

> Assign `18` to `age`.

---

## 2. Variable Naming Rules

Python variable names must follow these rules:

| Rule | Example | Valid? |
|---|---|:---:|
| Letters allowed | `name` | ✅ |
| Numbers allowed after the first character | `student1` | ✅ |
| Cannot start with a number | `1student` | ❌ |
| Underscore allowed | `student_name` | ✅ |
| Spaces not allowed | `student name` | ❌ |
| Special characters not allowed | `age$` | ❌ |
| Keywords cannot be used | `class` | ❌ |
| Case-sensitive | `age` vs `Age` | Different |

### Python Is Case-Sensitive

```python
age = 20
Age = 30
AGE = 40
```

These are **three different variables**.

---

## 3. Naming Convention: `snake_case`

Python commonly follows **snake_case** for variable names.

```python
student_name = "Rahul"
total_marks = 450
account_balance = 5000
phone_number = "9876543210"
```

Avoid unclear names:

```python
x = 450
y = 18
z = "Rahul"
```

Prefer meaningful names:

```python
total_marks = 450
age = 18
student_name = "Rahul"
```

> **Good variable names should clearly describe the data they represent.**

### Common Naming Styles

```python
student_name = "Rahul"    # Variable → snake_case
Student = "Rahul"         # Technically valid, but not recommended for variables
MAX_USERS = 100           # Constant convention
```

## 4. Basic Python Syntax

### Comments

Comments are used to explain code and are ignored by Python during execution.

#### Single-Line Comment

```python
# This is a single-line comment
student_name = "Rahul"
```

#### Multi-Line Comment

Python does not have a dedicated multi-line comment syntax. Triple-quoted strings are commonly used for multi-line documentation.

```python
"""
This is a multi-line block.
It can be used to write
long explanations.
"""
```

> **Note:** Triple-quoted text is technically a string literal, not a true comment.

### Special Characters in Variable Names

Variable names cannot contain special characters such as:

```text
@  #  $  %  &  -  !  ?  .
```

Examples:

```python
student@name = "Rahul"    # ❌
student-name = "Rahul"    # ❌
student$name = "Rahul"    # ❌
student.name = "Rahul"    # ❌
```

Use `_` instead:

```python
student_name = "Rahul"    # ✅
student_name_1 = "Aman"   # ✅
```

> **Important:** `_` (underscore) is allowed in Python variable names, but most other special characters are not.

---

## 5. Python Keywords

**Keywords** are reserved words that have special meaning in Python.

Examples:

```text
if, else, elif, for, while, def,
class, return, import, True, False, None
```

They cannot be used as variable names:

```python
class = 10      # ❌
if = 20         # ❌
```

But they can be part of a larger name:

```python
class_name = "B.Tech"    # ✅
```

To view Python's keywords:

```python
import keyword
print(keyword.kwlist)
```

# 6. Variable Examples

### Example 1: Student Information

```python
student_name = "Rahul"
student_age = 18
student_marks = 85
```

### Example 2: Updating a Variable

```python
age = 18
age = 19
```

The variable `age` now refers to `19`.

### Example 3: Multiple Variables

```python
first_name = "Rahul"
last_name = "Kumar"
city = "Patna"
```

### Example 4: Swapping Variables

```python
a = 10
b = 20
a, b = b, a
```

Now `a` is `20` and `b` is `10`.

# 8. Key Takeaways

- A **variable** is a name that refers to a value.
- `=` is the **assignment operator**.
- Variable names cannot start with numbers or contain spaces/special characters.
- Python is **case-sensitive**.
- Use meaningful names and preferably `snake_case`.
- Python **keywords** cannot be used as variable names.
- Variables store or refer to values using meaningful names.
- `=` assigns a value to a variable.
- Variable names must follow Python's naming rules.
- Python is case-sensitive.
- Use `snake_case` and meaningful names for variables.
- Python keywords cannot be used as variable names.

> **Remember:** A good variable name should make your code easy to understand without extra explanation.
