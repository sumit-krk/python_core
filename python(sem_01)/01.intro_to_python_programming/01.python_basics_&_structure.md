# Python Basics & Program Structure

## Basic Python Syntax

### Comments
```python
# This is a single-line comment
''' This is a
    multi-line comment '''
```

### Variables and Naming Conventions
```python
# Variable declaration
name = "John"
age = 25
height = 5.9

# Naming conventions (PEP 8)
my_variable = 10  # Use lowercase with underscores
MyClass = object  # Classes use CapWords
CONSTANT = 100    # Constants are UPPERCASE
```

## Structure of a Python Program

### Basic Program Structure

```python
# 1. Imports
import sys
from math import sqrt

# 2. Constants
PI = 3.14159
MAX_USERS = 100

# 3. Function definitions
def greet(name):
    """Function to greet a person"""
    return f"Hello, {name}!"

# 4. Class definitions
class Person:
    def __init__(self, name):
        self.name = name

# 5. Main code execution
if __name__ == "__main__":
    print(greet("World"))
    person = Person("Alice")
```

### Hello World Program
```python
print("Hello, World!")
```

## Input and Output

### Output using print()
```python
print("Hello, World!")
print("Name:", "John", "Age:", 25)
print("x =", 10, "y =", 20)

# Multiple arguments
print("a", "b", "c", sep="-", end="!\n")
```

### Input using input()
```python
name = input("Enter your name: ")
age = input("Enter your age: ")
```

### Type Conversion
```python
age = int(input("Enter age: "))
height = float(input("Enter height: "))
```

## Indentation

Python uses indentation to define code blocks:

```python
if age >= 18:
    print("You are an adult")
else:
    print("You are a minor")
```
