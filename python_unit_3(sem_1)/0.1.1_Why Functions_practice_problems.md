## H. Practical Problems

### 39. Welcome System

Create:

```python
welcome()
```

that displays:

```text
====================
Welcome to ABC College
====================
```

Call the function two times.

### 40. Student Profile

Create separate functions:

```text
student_name()
student_branch()
student_college()
```

Display:

```text
Name: Rahul
Branch: CSE
College: ABC College
```

### 41. College Information

Create:

```text
college_name()
college_branch()
college_course()
college_fee()
```

Call all four functions to display a simple college information page.

### 42. Repeated Heading

Create:

```text
section_heading()
```

that displays:

```text
--------------------
Student Information
--------------------
```

Use it before two different sections.

### 43. Mini Student Program

Create:

```text
welcome()
student_info()
course_info()
college_info()
```

Call them in a logical order.

### 44. Find the Repetition

Consider:

```python
print("Welcome")
print("Welcome")
print("Welcome")
print("Welcome")
print("Welcome")
```

Rewrite this using a function.

### 45. Improve the Organization

Consider:

```python
print("Welcome to ABC College")
print("Student: Rahul")
print("Branch: CSE")
print("Course: Python")
print("Fee: 50000")
```

Divide this program into meaningful functions and call them in the correct order.

### 46. Maintenance Challenge

Suppose the following message is displayed in many places:

```text
Welcome to ABC College
```

Create a function so that the message is written in only one place.

Then explain how changing the message inside the function helps maintenance.

### 47. Readability Challenge

Create a program whose main section looks approximately like:

```python
welcome()
student_info()
course_info()
fee_info()
```

Write the corresponding functions.

The goal is to make the main program understandable without reading every internal statement first.

### 48. Function Design Challenge

You have these tasks:

```text
Display welcome message
Display student information
Display college information
Display course information
Display fee information
```

Decide how many functions you would create and give each a meaningful name.

There can be more than one reasonable answer. Focus on clear organization.
