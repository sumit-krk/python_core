# Python: `math.ceil()`, `math.floor()` and `round()`

These functions change a number by rounding it. Import `math` before using `ceil()` or `floor()`:

```python
import math
```

## 1. `math.ceil(x)` — round up

Returns the **smallest integer greater than or equal to** `x`.

```python
import math

print(math.ceil(4.2))   # 5
print(math.ceil(4.0))   # 4
print(math.ceil(-4.2))  # -4
```

Think: move towards positive infinity (→ `+∞`).

## 2. `math.floor(x)` — round down

Returns the **largest integer less than or equal to** `x`.

```python
import math

print(math.floor(4.8))   # 4
print(math.floor(4.0))   # 4
print(math.floor(-4.2))  # -5
```

Think: move towards negative infinity (→ `-∞`).

## 3. `round(number, digits)` — round to the nearest value

Rounds to the nearest integer by default. The optional `digits` gives the number of decimal places.

```python
print(round(4.6))        # 5
print(round(4.2))        # 4
print(round(3.14159, 2)) # 3.14
print(round(1234, -2))   # 1200
```

## Quick comparison

| Function | Direction / rule | Result type | Example with `4.5` |
|---|---|---|---|
| `math.ceil(x)` | Always up | `int` | `5` |
| `math.floor(x)` | Always down | `int` | `4` |
| `round(x)` | Nearest value | usually `int` without `digits` | `4` |

## Tricky examples

### Negative numbers

```python
import math

x = -2.7
print(math.ceil(x))   # -2  (up, towards +∞)
print(math.floor(x))  # -3  (down, towards -∞)
print(round(x))       # -3  (nearest integer)
```

### `round()` and numbers ending in `.5`

Python uses **round half to even**. If a value is exactly halfway, it chooses the nearest even number.

```python
print(round(2.5))  # 2
print(round(3.5))  # 4
print(round(4.5))  # 4
print(round(5.5))  # 6
```

This rule helps reduce rounding bias when many numbers are rounded.

### Decimal places

```python
print(round(12.3456, 2))  # 12.35
print(round(12.3456, 0))  # 12.0
print(round(12.3456, -1)) # 10.0
```

How the second argument works:

- A **positive** value rounds digits after the decimal point.
- `0` rounds to the nearest whole number.
- A **negative** value rounds digits to the left of the decimal point.

| Code | What Python looks at | Result | Why? |
|---|---|---|---|
| `round(12.3456, 2)` | 2 decimal places | `12.35` | Keep `12.34`; the next digit is `5`, so it rounds up to `12.35`. |
| `round(12.3456, 0)` | nearest whole number | `12.0` | The decimal part is `.3456`, which is less than `.5`, so it rounds down to `12`. |
| `round(12.3456, -1)` | nearest tens place | `10.0` | `12.3456` is closer to `10` than to `20`. |

More examples with negative `digits`:

```python
print(round(146, -1))  # 150  → nearest 10
print(round(146, -2))  # 100  → nearest 100
print(round(146, -3))  # 0    → nearest 1000
```

> Note: `round(x, 0)` returns a `float`; `round(x)` (without the second argument) returns an `int` for ordinary floats.

## When to use which?

- Use `ceil()` when you need a whole number that is **enough**: rooms needed, pages needed, or buses needed.
- Use `floor()` when only complete units count: full boxes, completed hours, or array indexes.
- Use `round()` when you want the **closest** value: display marks, prices, or measurements.

```python
import math

students = 47
seats_per_bus = 20
print(math.ceil(students / seats_per_bus))  # 3 buses
```

## Practice exercises

1. Predict the output of `math.ceil(9.01)` and `math.floor(9.99)`.
2. What are the outputs of `math.ceil(-6.1)` and `math.floor(-6.1)`?
3. Write a program to round `98.7654` to 2 decimal places.
4. A box holds 12 items. Use `math.ceil()` to find the boxes needed for 85 items.
5. Explain why `round(6.5)` gives `6`, while `round(7.5)` gives `8`.

### Answers

1. `10`, `9`
2. `-6`, `-7`
3. `round(98.7654, 2)` gives `98.77`
4. `math.ceil(85 / 12)` gives `8`
5. Python chooses the nearest even integer for exact `.5` values.
