# ASCII and Unicode in Python

## 1. What Is ASCII?

**ASCII** stands for **American Standard Code for Information Interchange**.

ASCII is a character encoding standard that assigns a numeric value to characters such as letters, digits, punctuation marks, and control characters.

For example:

```python
print(ord("A"))
print(ord("a"))
print(ord("0"))
```

Output:

```text
65
97
48
```

The `ord()` function returns the Unicode code point of a single character. For ASCII characters, this value is the same as the ASCII value.

---

## 2. What Is Unicode?

**Unicode** is a universal character encoding standard designed to represent characters from languages and writing systems around the world.

ASCII covers a relatively small set of characters, while Unicode supports a much larger collection of characters.

For example:

```text
A
अ
中
€
```

In Python, strings support Unicode characters by default.

```python
print("Hello")
print("नमस्ते")
print("你好")
```

---

## 3. ASCII vs Unicode

ASCII and Unicode are related, but they are not the same thing.

| ASCII | Unicode |
|---|---|
| American Standard Code for Information Interchange | Universal character encoding standard |
| Represents a limited set of characters | Represents a very large set of characters |
| Uses values from `0` to `127` | Supports a much larger range of code points |
| Includes English letters, digits, punctuation, and control characters | Includes characters from many languages and writing systems |
| The first 128 Unicode code points correspond to ASCII | Includes ASCII characters plus many additional characters |

An important point is:

> **The first 128 Unicode code points correspond to the ASCII character set.**

# 4. Important ASCII Character Ranges

The following ranges are especially useful when learning Python character comparisons.

## Numbers (`0–9`)

The ASCII values of digits are:

```text
'0' -> 48
'1' -> 49
'2' -> 50
...
'9' -> 57
```

Therefore:

```text
'0' to '9' -> 48 to 57
```

## Uppercase Letters (`A–Z`)

```text
'A' -> 65
'B' -> 66
...
'Z' -> 90
```

Therefore:

```text
'A' to 'Z' -> 65 to 90
```

## Lowercase Letters (`a–z`)

```text
'a' -> 97
'b' -> 98
...
'z' -> 122
```

Therefore:

```text
'a' to 'z' -> 97 to 122
```

## Space Character

The space character has the value:

```text
' ' -> 32
```

---

# 5. Common Control Characters

Some character codes represent control characters rather than visible characters.

| Character | Meaning | Value |
|---|---|---:|
| `\t` | Tab | `9` |
| `\n` | Line Feed / New Line | `10` |
| `\r` | Carriage Return | `13` |
| Space | Space character | `32` |

For example:

```python
print(ord("\t"))
print(ord("\n"))
print(ord("\r"))
print(ord(" "))
```

Output:

```text
9
10
13
32
```

---

# 6. The `ord()` Function

Python provides the built-in `ord()` function to find the Unicode code point of a character.

For ASCII characters, the returned value is their ASCII value.

### Syntax

```python
ord(character)
```

Example:

```python
print(ord("a"))
```

Output:

```text
97
```

Another example:

```python
print(ord("A"))
print(ord("Z"))
print(ord("0"))
print(ord("9"))
```

Output:

```text
65
90
48
57
```

### Important

`ord()` expects a string containing exactly **one character**.

This is valid:

```python
print(ord("a"))
```

But this produces an error:

```python
print(ord("abc"))
```

because `"abc"` contains more than one character.

---

# 7. The `chr()` Function

The opposite of `ord()` is the `chr()` function.

`chr()` converts a Unicode code point into its corresponding character.

Example:

```python
print(chr(65))
print(chr(97))
print(chr(48))
```

Output:

```text
A
a
0
```

So remember:

```text
ord() -> Character to number
chr() -> Number to character
```

---

# 8. Character Comparison in Python

Python can compare strings using comparison operators such as:

```text
>
<
==
!=
>=
<=
```

When strings are compared, Python compares their characters according to their Unicode code points.

For ASCII characters, this means their ASCII values are used.

For example:

```python
print("4" > "1")
```

Output:

```text
True
```

Why?

```text
'4' -> 52
'1' -> 49
```

Since:

```text
52 > 49
```

the result is:

```text
True
```

---

# 9. Important Example: `"4" > "11"`

Consider:

```python
print("4" > "11")
```

Output:

```text
True
```

This can look confusing at first.

Python is **not comparing the numbers `4` and `11`** here. Both values are strings.

Python compares strings character by character.

The first characters are:

```text
"4" -> 52
"1" -> 49
```

Since:

```text
52 > 49
```

Python determines:

```text
"4" > "11" -> True
```

The important lesson is:

> **String comparison is not the same as numerical comparison.**

---

# 10. Example: `"327" < "331"`

Consider:

```python
print("327" < "331")
```

Output:

```text
True
```

Python compares the strings from left to right.

First:

```text
3 == 3
```

So Python moves to the next characters:

```text
2 < 3
```

Therefore:

```text
"327" < "331" -> True
```

---

# 11. Example: `"aa" > "b"`

Consider:

```python
print("aa" > "b")
```

Output:

```text
False
```

Python compares the first characters first:

```text
'a' -> 97
'b' -> 98
```

Since:

```text
97 < 98
```

Python already knows that `"aa"` is less than `"b"`.

The second `"a"` does not need to be considered.

Therefore:

```text
"aa" > "b" -> False
```

---

# 12. Example: `"b" > "apple"`

Consider:

```python
print("b" > "apple")
```

Output:

```text
True
```

Python compares the first characters:

```text
'b' -> 98
'a' -> 97
```

Since:

```text
98 > 97
```

Python determines that `"b"` is greater than `"apple"`.

The different string lengths do not matter because the comparison is already decided by the first different character.

---

# 13. Example: `"4" > "a"`

Consider:

```python
print("4" > "a")
```

Output:

```text
False
```

Compare their Unicode values:

```text
'4' -> 52
'a' -> 97
```

Since:

```text
52 < 97
```

we get:

```text
"4" > "a" -> False
```

# 14. Why Does Uppercase Come Before Lowercase?

Look at the Unicode values of some letters:

```python
print(ord("A"))
print(ord("a"))
```

Output:

```text
65
97
```

Therefore:

```text
'A' < 'a'
```

because:

```text
65 < 97
```

This also affects string comparison.

For example:

```python
print("Apple" < "apple")
```

Output:

```text
True
```

The first characters are compared:

```text
'A' -> 65
'a' -> 97
```

Therefore:

```text
"Apple" < "apple"
```

---

# 15. Important Rule for String Comparison

When Python compares strings, remember these steps:

1. Compare characters from left to right.
2. Compare their Unicode code points.
3. If the characters are equal, move to the next character.
4. At the first different character, the comparison is determined.
5. If one string is a prefix of the other, the shorter string is considered smaller.

Example:

```python
print("abc" < "abd")
```

Comparison:

```text
a == a
b == b
c < d
```

Therefore:

```text
True
```
